# 기획: 한 달을 넘기는 학습 습관 — 리텐션 콘텐츠 팩

> 작성: 2026-07-16 · 상태: P1 구현 착수 (이 문서가 스펙 겸용)
> 벤치마크: Duolingo(스트릭 보호·일일 퀘스트·마일스톤 축하), Snapchat(스트릭 감정 자산),
> 말해보카/Speak(실력 체감 증명), Toss 만보기(주간 리포트)

## 한 줄 요약

"오늘 하루 안 하면 끝"인 현재 루프에 **용서(책갈피) · 다양성(오늘의 미션) ·
축하(마일스톤)** 세 장치를 더해, 학습 습관이 한 달을 넘기게 만든다.

## 왜 지금 필요한가 (갭 분석)

현재 리텐션 장치 인벤토리: 오늘의 목표(고정 소량), 스트릭 잔디, XP/레벨,
업적 9종, 주간 학습 랭킹(친구), 게임 6종+명예의 전당, 20시 푸시, 데일리 퍼즐.

| 구간 | 현재 상태 | 갭 |
|---|---|---|
| 1~7일 | 온보딩 체크리스트·데일리 목표로 커버 | 없음 (양호) |
| **7~30일** | 스트릭이 유일한 동력인데 **하루 놓치면 즉시 0** | **이탈 최다 구간이 무방비** |
| 매일의 루프 | 복습→(가끔) 게임. 할 일이 단조로움 | 오늘 왜 게임도 해야 하는지 이유 없음 |
| 성취 체감 | 업적은 1회성, 레벨은 완만 | 7·30일 순간을 아무도 축하 안 함 |

핵심 근거: Duolingo 가 공개적으로 밝혀온 최상위 리텐션 레버가 **스트릭 + 스트릭
보호 아이템**이고 (놓친 다음 날 복귀율이 보호 장치 유무로 크게 갈림), 일일
퀘스트는 DAU 당 세션 다양성을 늘린 검증 장치다. 스트릭 마일스톤 축하·공유는
Snapchat 스트릭이 증명한 감정 자산화 패턴.

## 저작권 안전선 (필수 준수)

- **메커니즘(규칙·수치·루프)은 아이디어 영역이라 저작권 보호 대상이 아님** —
  차용 가능. 보호 대상은 **표현**: 명칭·캐릭터·그래픽·문구·UI 조형.
- 따라서: 타사 명칭("Streak Freeze", "리그" 고유명 등)·마스코트·아이콘·안내
  문구를 그대로 쓰지 않는다. 모든 표현은 **노트 x 레고 테마의 자체 언어**로:
  책갈피(동결), 오늘의 미션+도장(퀘스트), 잉크 축하 카드(마일스톤).
- 상표 주의: "듀오링고" 등 타사명을 UI·마케팅 문구에 노출하지 않는다.

## P1 — 이번 구현 (3종)

### 1. 책갈피 (스트릭 보호)

하루 놓쳐도 책갈피가 자동으로 끼워져 연속 학습이 끊기지 않는다.

- **지급**: 오늘 복습이 데일리 목표에 도달하면 지급 시도 — 같은 ISO 주에 1개,
  최대 2개 보유. (매일 지급하면 긴장이 사라지고, 유료 재화는 우리 서비스에 없음)
- **소모**: 스트릭 계산 시 어제까지의 공백(gap)을 만나면 보유분 한도 내에서
  자동 소모해 이어붙임. 공백 뒤(과거 방향)에 활동일이 있을 때만 소모 (낭비 방지).
- **의미**: 책갈피 날은 스트릭 일수에 +1 되지 않고 "리셋만 방지" (Duolingo 동일
  규칙 — 공짜 진행은 없음).
- **데이터**: `user_settings.streak_savers`(보유), `user_settings.saver_award_week`
  (주 1회 지급 가드), `streak_saver_uses(user_id, date)` (소모 원장, 잔디 표기용).
- **UI**: 오늘의 목표 카드 스트릭 영역에 책갈피 보유 배지 + 잔디에 책갈피 날 표기.

### 2. 오늘의 미션 (일일 퀘스트 3종 + 도장)

매일 다른 미션 3개 — 복습 코어 1개 고정 + 풀에서 2개 날짜 결정적 로테이션.

- **풀** (진행도가 기존 로그에서 파생 가능한 것만): 복습 10개(고정) / 정답률
  80%로 10개 / 게임 1판 / 데일리 퍼즐 도전 / 새 카드 5개 만나기.
- **선택**: 랑데부 해싱 `md5(f"{day}:{user_id}:{key}")` — 데일리 퍼즐과 동일
  패턴, 풀이 늘어도 안정적.
- **보상**: 미션당 XP 20~30 + 3개 전부 달성 보너스 30. XP 는 실시간 집계
  원칙이지만 미션 보너스는 "완료 순간"이 상태라 **`quest_completions` 원장**에
  적립 (PK: user_id+date+quest_key 멱등, stats XP 에 합산).
- **UI**: 홈 오늘의 목표 카드 아래 미션 카드 — 도장 3칸, 완료 시 초록 도장.

### 3. 마일스톤 축하 (7·14·30·50·100·200·365일)

- 스트릭이 마일스톤에 도달한 첫 진입에 축하 모달 (프론트 전용,
  localStorage 중복 가드) + 기존 공유 이미지(share-image.ts)로 자랑하기.
- 게임 결과 공유와 동일한 캔버스 카드 — 신규 에셋 없음.

## 거절한 대안

- **리그(승강제 코호트)**: Duolingo 최강 장치지만 코호트당 활성 사용자 수십 명
  필요 — 현재 DAU 로는 유령 리그가 되어 역효과. 재검토 트리거: DAU 100+.
- **하트/생명 제한**: 학습 중단 페널티는 수익화 장치이지 학습 장치가 아님 —
  무료 서비스에서 마찰만 추가.
- **책갈피 유료/재화 판매**: 재화 경제 없음. 주 1회 무료 지급이 긴장과 용서의
  균형점.
- **미션 서버 저장 로테이션**: 저장하면 시간대 버그·백필 문제 — 날짜 결정적
  해싱이면 저장 없이 항상 같은 결과 (데일리 퍼즐로 검증된 패턴).

## 성공 지표

- 7일+ 스트릭 사용자의 8~30일 잔존율 (책갈피 소모 후 다음 날 복귀율)
- 일일 미션 3개 완료율, 미션 경유 게임 세션 수
- 마일스톤 공유 이미지 생성 수
