# 기획: 단어 인사이트 — 유사단어 + 단어 정보 카드

> 작성: 2026-07-13 · 상태: 방향 제안 (스펙 전 단계)
> 벤치마크: 말해보카 오답노트 (유사 어휘·뉘앙스·격식 설명 — 사용자 호평 기능)

## 한 줄 요약

학습 중 단어를 탭하면 **뉘앙스·유사단어·문맥 예문**을 보여주는 카드를 제공하고,
오답이 "유사단어"였을 때 비교 카드를 자동 노출해 **오답을 학습 기회로 전환**한다.

## 왜 지금 필요한가 (사용자 문제)

1. 학습 피드백 화면에 뜻 한 줄만 있어 "efficient 랑 effective 가 뭐가 다르지"
   순간에 정보가 없음 — 오답의 주 원인인 **유사단어 혼동**이 해소되지 않고 반복됨
2. 현재 선다 오답 선지가 랜덤이라 너무 쉬움 — 유사단어 기반 선지가 없으면
   변별 학습이 안 됨
3. 말해보카가 증명한 수요: 오답노트의 뉘앙스·격식 설명이 리뷰에서 가장
   자주 언급되는 강점

## 차별화 포인트 (말해보카 대비)

**"내가 본 영상의 문맥"과 연결된 단어 정보.** 범용 사전 설명이 아니라,
사용자가 학습한 유튜브 스크립트 문장을 예문 1순위로 쓴다 — 학습과 게임이
공유하는 "내 콘텐츠 선순환" 설계의 연장.

## 기능 범위

### 단어 정보 카드 (바텀시트)

| 섹션 | 내용 | 소스 |
|---|---|---|
| 헤더 | 단어 + IPA + TTS 재생 + 품사 | LLM 생성 (1회, 캐시) |
| 핵심 뜻 | ko_text + 뉘앙스·격식 한 줄 (구어/문어, 긍/부정 톤) | LLM 생성 |
| 예문 | 2개 — **내 영상 문맥 우선**, 부족하면 생성 | occurrence 문맥 → LLM 보충 |
| 콜로케이션 | 자주 붙는 표현 3개 (`make a decision` 식) | LLM 생성 |
| 유사단어 | 유의어 3-5 + 혼동어("언제 이걸 쓰나" 한 줄 비교) | LLM + 임베딩 후보 |

### 유사단어 비교 (말해보카 핵심 UX 흡수)

- 오답 제출값이 정답의 유사단어면 **"아깝다!"** 판정 + 두 단어 비교 카드 자동 노출
  (뜻 차이 한 줄 + 예문 대비 2개)
- 비교 카드에서 유사단어를 **원탭으로 학습 큐에 추가** → 어휘망 확장 루프

### 진입점 (동기가 가장 높은 순간 우선)

1. 학습 정답/오답 피드백 화면 — 단어 탭 (말해보카 오답노트 포지션)
2. 라이브러리 단어 목록
3. 게임 결과 화면의 틀린 단어

## 데이터·기술 설계 방향

- **`word_insights` 테이블**: item_id FK + JSONB(ipa, pos, nuance, examples[],
  collocations[], synonyms[], confusables[]) + generated_at
- **생성 시점: lazy** — 최초 조회 때 LLM 생성 후 영구 캐시 (파이프라인 일괄 생성
  대비 비용 최소화, 조회된 단어만 생성). 생성 중엔 스켈레톤 UI
- **유사단어 후보**: 서버에 이미 상주하는 **qdrant** 에 단어 임베딩 저장 →
  (1) 카드의 유사단어 후보 (2) 선다 오답 선지 품질 개선 (3) "아깝다" 판정에 재사용
- 비용 가드: 단어당 LLM 1회(수백 토큰) + 사용자 무관 공유 캐시(learning_items 가
  전역 공유이므로 1단어 1회면 끝)
- 품질 가드: 예문은 내 영상 문맥 우선으로 환각 여지 축소, 카드에 "잘못됐어요"
  신고 플래그 → 백오피스 재생성

## 단계 로드맵

| 단계 | 범위 | 핵심 지표 |
|---|---|---|
| P1 (MVP) | 단어 정보 카드(lazy 생성) + 학습 피드백 진입점 | 카드 열람률, 열람 후 재정답률 |
| P2 | 임베딩 유사단어 + "아깝다" 판정 + 비교 카드 + 오답 선지 품질 개선 | 유사단어 오답률 감소 |
| P3 | 유사단어 원탭 학습 추가 + 어휘망 뷰 | 유사단어→학습 전환율 |

## 결정 필요 항목

1. P1 에서 TTS 포함 여부 (브라우저 SpeechSynthesis 면 무료 — 포함 권장)
2. 카드 생성 LLM 모델 티어 (haiku 급이면 충분한지 품질 샘플 검증 필요)
3. "아깝다" 판정 기준 — 임베딩 유사도 임계값 vs LLM confusables 목록 매칭
   (P2 에서 A/B 검증)

## 리스크

- 2GB 서버: qdrant 상주라 추가 인프라 없음, 임베딩 생성만 파이프라인에 추가
  (배치, 저부하) — 게임/학습 루프와 격리 필요 (이벤트 루프 블로킹 금지)
- LLM 비용: lazy + 전역 캐시로 상한 자연 형성 (활성 어휘 수에 수렴)
