## 한 줄 결론

**카테고리 분리(토익식)가 아니라 문장 카드의 형식 사다리가 답이다** — 레벨
1~3 을 "전체 문장 칩 조립" 하나로 뭉뚱그린 chat 덱 예외를 레벨별 4단 형식
(선다 → 청크 조립 → 단어 조립 → 타이핑)으로 펴고, 저레벨에는 길이 게이트와
세션 혼합 캡을 건다.

## 문제 실측 (2026-08-18 프로드 읽기 전용)

| 실측 | 값 | 함의 |
|---|---|---|
| 사용자 학습 난이도 | **전원 study_level 2 (초급)** — 4/4명 | 이 문제가 전 사용자에게 적용 |
| 대표 사용자 카드 구성 | due 258장 중 **문장 81장 (31%)** — 전부 chat 덱 | 초급 세션 3문항 중 1개가 문장 조립 |
| chat 문장 길이 분포 | 194문장 중 9단어 이상 33개(17%), 최장 **41단어** | 41단어 = 칩 44개 조립 문제가 초급에게 출제 |
| 일반 콘텐츠 sentence | 레벨 4 전용이라 초급에 안 나옴 | 문제는 chat 덱 예외 경로에서만 발생 |

### 인지 부하의 실제 모습

초급(레벨 2) 세션 리듬: 4지선다(응답 2~5초) 사이에 칩 10~44개 조립(1분+)이
불규칙하게 끼어든다. 문항 간 부하 격차가 크면 "짧고 쉬운 반복"이라는 세션
계약이 깨지고, 긴 문항 앞에서 이탈한다 — 사용자 보고("집중력이 떨어져서 학습을
더 안 하게 됩니다")와 일치.

### 원인 구조 (설계 결함 위치)

1. 레벨 축이 **콘텐츠 타입과 답 형식을 한 몸으로** 묶고 있다 (word=선다,
   idiom=빈칸, pattern=부분 조립, sentence=타이핑 — learning.md).
2. chat 덱 예외(2026-08-14, "초급이 자기 덱을 못 본다" 해소)가 이 축을 뚫으면서
   형식 사다리 없이 **레벨 1~3 = 전체 문장 칩 조립 단일 형식**으로 뭉뚱그렸다
   (my-phrases.md 레벨별 학습카드). 길이 상한도 없다.
3. 부수 발견: 레벨로 잠긴 타입의 기존 카드(대표 사용자 pattern 24장)가 due 인 채
   큐에서 영원히 안 나온다 — 죽은 카드 (별도 이슈로 분리).

## 타사 벤치마크 (2026-08-18 리서치)

### 듀오링고 — 형식 사다리의 표준 사례 (신뢰도 HIGH)

- 초급 문장 문제의 기본형은 **word bank(칩 탭)** — A1 의 의도적 스캐폴드.
  공식 블로그가 쓰기 지도 순서를 "**단어 → 짧은 구 → word bank → 자유 작문**"
  으로 명시 — 우리 A안 사다리(선다→청크→단어칩→타이핑)와 같은 구조.
- word bank 와 키보드 입력은 **요구하는 active recall 수준이 다르다**(공식
  해설) — 같은 문장이라도 형식이 난이도를 결정한다는 것이 그들의 설계 전제.
  타이핑 전환은 문제별 토글, 어려운 문항은 Birdbrain 이 적응 선택.
- 진짜 완화 장치는 칩 개수가 아니라 **문장을 기학습 재료로 채우고 새 정보를
  한 조각만 넣는 것**(코스 제작 포스트가 인지부하를 직접 근거로 언급) + 회상
  확률 ~50%(HLR Goldilocks) 겨냥. — 내가 쓰는 말 덱은 **원문이 내 발화**라
  "새 정보 = 번역 표현뿐"인 이상적 조건. 저레벨 노출 자체는 타당하고, 문제는
  형식·길이뿐이라는 방증.
- 핵심 세션은 스킬 트랙 분리가 아니라 **혼합 연습**. 스킬별 표면(Stories/
  DuoRadio)은 별도 몰입 콘텐츠 (우리의 게임·라이브러리 포지션과 동일 구조).

### 학습과학 — 형식 위계와 이탈 (신뢰도 HIGH)

- **recognition(선다) → cued recall(조립·빈칸) → free recall(타이핑)** 난이도
  위계는 확립된 연구 결과 (Rowland 2014 · McDermott 2021 리뷰). 초심자는
  cued/guided recall 을 먼저 거친 뒤 free recall 로 올리는 스캐폴딩 권장.
- desirable difficulty 는 **인출에 성공할 때만** 유효 — 실패가 반복되면
  학습 이득이 사라지고 좌절·이탈로 이어진다 (언어 학습은 원래 중도 포기율이
  높은 도메인). "초급에게 41단어 조립"은 undesirable difficulty 의 전형.
- 작업기억 한계(WM 4±1 청크)를 넘으면 암송 불가 → 의미 재구성 부담으로 전환.
  저숙련자는 청크 크기 자체가 작아 같은 문장도 초급에겐 넘친다 — **A안 청크
  조립의 "칩 최대 4개"는 WM 한계 정합**. 처방은 의미 청크 경계 분절 + 따라
  말하기 (Ellis & Sinclair 1996).
- interleaving(혼합 출제)은 훈련 중 오답을 늘리지만 지연 평가 정확도가 높다
  — **B안(트랙 분리) 기각의 과학적 근거** (혼합 세션 유지).

### 트랙 분리 vs 혼합 — 업계 패턴 (신뢰도 MEDIUM)

**시험 대비 = 분리형, 일반 습득 = 혼합형.** Busuu·Babbel·LingoDeer 는 한
레슨에 어휘·문법·듣기·읽기를 통합(혼합 세션), 산타토익만 진단 후 취약 파트
집중 트랙 — 시험 형식 미러링이 목적. 리얼클래스는 초급을 "열 단어 내외 문장"
으로 규정 (길이 게이트 8단어의 방증). **초급 칩 개수 상한의 공개 수치는
어디에도 없다** — 우리 값(칩 4개·8단어·캡 5개)은 배포 후 응답 시간·오답률
관측으로 자체 보정한다 (§평가 기준).

출처: Duolingo 블로그 3편(writing-skills · course-creation · difficult-
exercises) · HLR 논문(settles.acl16) · 문항 난이도 논문(portnoff.edm21) ·
retrieval practice 문헌(doi 10.3390/bs16071124 외) · Ellis & Sinclair 1996 ·
산타토익·리얼클래스 서비스 페이지 (자사 기술이라 독립 검증 불가).

## 설계안 비교

### A안 (권장) — 문장 형식 사다리 + 부하 캡 (구조 유지, 수술적)

레벨은 유지하되, **"무엇을(타입)"과 "어떻게(형식)"를 분리**한다. chat 문장
카드의 답 형식이 레벨을 따라 recognition → cued recall → free recall 로 올라간다:

| study_level | chat 문장 형식 | 인지 단계 | 예상 응답 시간 |
|---|---|---|---|
| 1 입문 | **뜻 매칭 선다** — 내 원문(ko) 제시, 같은 덱 문장 4개 중 번역문 선택 | recognition | 5~10초 |
| 2 초급 | **청크 조립** — 문장을 2~4덩이로 나눠 배열 (칩 최대 4개, 방해칩 0~1) | cued recall (저부하) | 10~20초 |
| 3 중급 | **단어 칩 조립** (현행) — 방해칩 2개 | cued recall | 20~40초 |
| 4 고급 | **전체 타이핑** (현행) | free recall | 타이핑 |

보조 장치 2종:

1. **길이 게이트**: 레벨 1~2 큐에는 **8단어 이하** 문장만 출제 (현 수집분의
   73% 커버). 9단어+ 문장은 카드가 있어도 레벨 3 진입까지 대기 — 게임(타자·
   받아쓰기)은 종전대로 전 문장 사용. 대기 카드는 덱 편집 화면에 "레벨 3부터"
   배지로 보이게 해 사라진 게 아님을 알린다.
2. **세션 혼합 캡**: study_level ≤ 2 인 사용자의 큐 페이지(20문항)당 문장 카드
   **최대 5개** — 선다 위주 리듬을 지키고, 문장 백로그(대표 사용자 due 81장)는
   여러 날에 걸쳐 소화된다. FSRS due 는 그대로 — 출제 순서만 제어.

구현 스코프 (예상 4~6파일, 신규 화면 0):

- backend `services/quiz.py`: 형식 분기 (`_sentence_assemble_question` 레벨
  분기 + 청크 분해 + 뜻 매칭 선다), `api/study.py`: 길이 게이트·혼합 캡
- frontend `session/page.tsx`: 뜻 매칭 선다는 기존 choice UI 재사용, 청크
  조립은 기존 칩 UI 재사용 (칩=청크 문자열) — 신규 컴포넌트 0
- 스펙: my-phrases.md §레벨별 학습카드 표 개정 + learning.md §큐 구성

### B안 — 토익식 카테고리 분리 (단어/듣기/문장/독해 트랙)

**기각 권고.** 근거:

1. **혼합 세션(interleaving)이 이 앱의 과학적 코어다** — FSRS 는 "잊을 때가 된
   카드"를 타입 무관하게 불러온다. 트랙을 나누면 스케줄이 파편화되고 "오늘 어느
   트랙?"이라는 선택 비용이 생긴다 (effectiveness-audit 인지 부하 경고와 정면
   충돌 — 표면 동결 원칙).
2. **스킬 표면은 이미 사실상 존재한다** — 듣기(받아쓰기·리스닝 빙고·A-B 루프·
   섀도잉), 문장(타자·어순), 단어(테트리스·퀴즈로얄), 독해(루틴·요약). 부족한
   것은 트랙이 아니라 **형식-레벨 정합**이다.
3. 토익 앱의 파트 분리는 **시험 형식 대비**가 목적 — 우리는 습득(acquisition)
   지향이라 전제가 다르다. 습득 지향 앱(듀오링고 등)은 혼합 세션이 표준.
4. DAU 4명 단계에서 트랙 4개 분리는 과설계 (Simplicity Ladder 1칸: 안 만든다).

단, B안의 취지("형식별 예측 가능성")는 A-2 혼합 캡이 흡수하고, 게임 탭에 스킬
라벨(단어/듣기/문장) 그룹핑을 P2 로 남긴다 — 표면 증설 없이 라벨만.
(P2 구현 완료 2026-08-18 — 게임 허브 카드에 스킬 칩 + 같은 스킬 인접 정렬)

### C안 — chat 덱 예외 철회 (문장은 레벨 4 전용으로 회귀)

기각. "초급이 자기 덱을 아예 못 보는 갭"(2026-08-14 해소 이유)이 재발한다.
내가 쓰는 말은 이 앱의 유일한 자기 생성 콘텐츠 — 초급에게 닫으면 성장 루프
(채팅→덱→복습→채팅)가 초급 구간에서 끊긴다.

## 평가 기준 (구현 시)

- 완성도: 레벨 1~4 형식 사다리 + 게이트 + 캡 구현, 스펙 동기화
- 견고성: 형식별 채점 회귀 테스트 (기존 compose 채점 경로 재사용 검증),
  덱 4문장 미만 시 선다 폴백
- 관측: 문장 문항 응답 시간·오답률의 레벨별 분포 (usage-events 재사용) —
  배포 후 "집중력 저하" 개선의 정량 증거
