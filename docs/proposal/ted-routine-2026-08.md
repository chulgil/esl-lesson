## 한 줄 결론

우리 앱은 이 루틴의 **어휘 파이프라인(추출->FSRS->오답 정리)은 이미 상위 호환**이다.
비어 있는 것은 **콘텐츠 한 편을 "갈아 넣는" 여정** — 듣기 훈련의 구조화, 섀도잉·녹음,
그리고 **요약해 말하기(액티브 인출)**다. 카드 단위 학습에 콘텐츠 단위 루틴을 얹는다.

## 원리 추출 (10단계의 뼈대)

| # | 원리 | 근거 (노트) |
|---|---|---|
| A | **다 이해하기를 포기, 중심 내용 파악 훈련** | 외국어 전부 이해는 평생 불가 — 중심 문장 뒤 근거·예시로 역추적 |
| B | **의식적 분석 없는 노출은 무효** | 미드 하루 종일 시청 실험 실패 — 성인은 그냥 들어선 안 트임 |
| C | **60~80% 이해 자료 + 짧고 구조 있는 영상** | 컴프리헨서블 인풋, 구조가 명확해야 사고방식이 옮아옴 |
| D | **안 들리는 원인은 3개뿐: 단어/문법/연음** | 원인 미특정이 "공부해도 안 들리는" 이유 |
| E | **단어는 하루 10개, 중심 파악 필수어만** | 30~100개 억지 암기는 하나도 안 남음 |
| F | **어원 레버리지** | 접두·접미사를 알면 안 외운 단어가 이해됨 (10개가 30개 되는 지점) |
| G | **듣기 오답노트** | 화자가 "이것만 가져가도 다 얻는 것" |
| H | **이해 후 섀도잉 (느리게->원속도->자막 없이) + 인토네이션** | 분석 없는 섀도잉 = 외계어 속도 흉내 |
| I | **녹음 1~3분 — 가장 하기 싫고 가장 효과적** | 운동 자세 촬영과 같은 객관화 |
| J | **요약해 말하기/쓰기 — 액티브 인출** | 패시브 대비 약 2배 암기 효과. "누가 알려줬다면" 한 단계 |
| K | **계단식 성장 멘탈** | 정체 구간을 실패로 읽지 않기 |

## 현황 매핑 — 있음 / 부분 / 없음

| 원리 | 앱 현황 | 판정 |
|---|---|---|
| E 단어 큐레이션 | AI 4종 추출이 쉬운 표현 제외 + `daily_new_limit` 설정 | **있음** (상위 호환 — FSRS 가 "하루 10개"보다 정밀) |
| G 오답노트 | 오답 정리 모드(`?mode=weak`) + 세션 내 재출제 | **있음** (듣기 특화는 아님) |
| B 의식적 분석 | 카드 학습 자체가 의식적 인출 | **있음** (단, 콘텐츠 단위 분석은 없음) |
| A 중심 내용 파악 | 시험(exam)은 세부 문항 위주 — "이 영상의 메시지" 문항 없음 | **없음** |
| C 자료 수준 선택 | 라이브러리에 난이도·이해도 표시 없음 | **없음** |
| D 원인 3분류 | 오답 피드백은 정답 제시뿐 — 원인 태깅 없음 | **없음** |
| F 어원 | word-insight(뉘앙스·유사어·예문)에 어원 필드 없음 | **부분** |
| H 섀도잉 | A-B 루프(문장 구간 반복)는 재료로 완비 — 속도 조절·자막 가리기·단계 없음 | **부분** |
| I 녹음 | 없음 (받아쓰기 게임은 딕테이션 계열 — 노트 기준 비효율 훈련) | **없음** |
| J 요약 인출 | 없음 — 학습 완료 후 아웃풋 단계 부재 | **없음** |
| K 계단식 멘탈 | 장기 기억 지표·잔디·마일스톤이 유사 역할 | **있음** |

## 채택 기획

### P1-1. 콘텐츠 루틴 가이드 — "이 영상 갈아 넣기" (원리 A·B·H·J 의 골격)

라이브러리 상세에 콘텐츠당 **3파트 여정 체크리스트**를 얹는다 (카드 학습과 병행되는
콘텐츠 단위 진행):

```
파트 1 듣기   [1] 자막 없이 전체 듣기 (흐름만)   [2] 중심 문장 찾으며 다시 듣기
파트 2 분석   [3] 문장 단위 직해 (A-B 루프)      [4] 추출 카드 학습 (기존 FSRS)
파트 3 체화   [5] 섀도잉 (P1-2)                  [6] 한 문장 요약 (P1-3)
```

- 데이터: `content_routine_progress(user_id, content_id, step, done_at)` — 단계 체크 원장
- UI: 라이브러리 상세 상단에 진행 브릭 6칸. 각 단계에 그 자리에서 실행되는 CTA
  (예: [1]은 자막 숨김 재생, [4]는 `?content_id=` 덱 학습으로 연결)
- 전 단계 완료 시 XP 보너스 + "갈아 넣은 영상" 카운트 (업적 후보)

### P1-2. 섀도잉 모드 (원리 H — 기존 A-B 루프 확장)

| 요소 | 내용 |
|---|---|
| 3단 진행 | 1) 자막 보며 0.75x -> 2) 원속도 -> 3) **자막 가리고** 원속도 (노트의 3단계 그대로) |
| 구현 | YouTube IFrame `setPlaybackRate` + 기존 구간 반복 + 자막 blur 토글 — 신규 API 불필요 |
| 진입 | 라이브러리 상세 "섀도잉" 토글 — 문장별 반복 횟수 배지 |
| 가드 | 루틴 가이드에서 파트 2(분석) 이후 단계로 배치 — "이해 후 섀도잉" 원리를 UI 순서로 강제 |

### P1-3. 한 문장 요약 — 액티브 인출 (원리 J, 화자가 가장 아쉬워한 단계)

- 학습 여정 마지막 단계: "이 영상의 메시지를 영어 한 문장으로" 입력
- 채점: Claude 로 **의미 충실도 판정** (레벨 4 문장 2차 채점과 동일 패턴 — 모범 요약과
  의미 비교, 문법 교정 코멘트 1줄). 정답/오답이 아니라 **피드백형** (완벽주의 방지, 원리 A)
- 저장: `content_summaries(user_id, content_id, text, feedback, created_at)` — 다시 보기
- 보상: 제출 시 XP (시험 제출과 동일 결) — 아웃풋 습관화

### P1-4. 어원 레버리지 (원리 F — word-insight 확장)

- `word_insights` 페이로드에 `etymology` 필드 추가: 어근·접두/접미사 분해 + 같은 어근
  단어 2~3개 (LLM 생성, 기존 캐시 파이프라인 그대로)
- UI: 단어 정보 카드에 "어원" 절 — "10개가 30개 되는" 어휘 확장 레버리지

### P2 (관측 후)

| 후보 | 내용 | 원리 |
|---|---|---|
| 녹음 비교 | MediaRecorder 로 1~3분 구간 녹음 -> 원음과 교차 재생 (STT 채점은 그 다음) | I |
| 오답 원인 태깅 | 오답 피드백에서 "단어/문법(구어)/연음" 셀프 태깅 -> 오답 정리를 원인별 필터 | D·G |
| 콘텐츠 난이도 배지 | 추출 항목 난이도 분포 + 내 카드 겹침으로 "이해 예상 60~80%" 표시·추천 | C |
| 시그널 표현 하이라이트 | 자막에서 `here's what I found` 류 시그널 표현을 하이라이트 — 중심 문장 감각 훈련 | A |
| 중심 내용 4지선다 | 시험에 "이 영상의 메시지는?" 문항 자동 생성 | A |

### 기각

- **딕테이션(전문 받아쓰기) 강화** — 노트 원리: 받아쓰기는 시간 대비 비효율.
  기존 받아쓰기 게임은 "변주·보상"으로만 유지, 루틴의 훈련 축으로 승격하지 않는다.
- **색깔 회차 추적(3단계)의 직접 이식** — 종이 노트 고유의 훈련. 앱에서는 섀도잉
  반복 카운트와 원인 태깅(P2)이 같은 진단 정보를 대체한다.

## 기존 전략과의 정합

- duolingo-benchmark 의 결론("실전 유튜브 콘텐츠가 최대 차별점")을 **학습법으로 완성**
  하는 기획이다 — 듀오링고는 콘텐츠가 합성이라 이 루틴 자체가 불가능하다.
- user-journey-motivation 의 피크엔드와 연결: 여정 완료(6칸) 순간이 콘텐츠 단위의
  새로운 피크가 된다.
- 원리 K(계단식 성장)는 기존 장기 기억 지표가 담당 — 추가 장치 불필요.

## 성공 지표

- 루틴 가이드 노출 후 콘텐츠당 평균 완료 단계 수 / 6칸 완주율
- 요약 제출 수·재제출률 (액티브 인출 습관화)
- 섀도잉 모드 사용 콘텐츠의 카드 정답률 vs 미사용 (체화 효과 관측)
