# 기획: Cake(케이크) 벤치마크 — "심플하지만 기능은 다 있는" UX 흡수

> 작성 2026-08-21 · 상태: **전 항목(C1~C7, P1·P2) 반영 완료 — 프로덕션 배포됨 (2026-08-21)**
> 요청: "케이크 앱과 비교해 장점을 흡수. 심플하면서도 기능이 다 있는 UI/UX.
> 모바일 우선 — 홈이 한 화면에 스크롤 없이. 글자 축소 + 가운데 정렬."

## 0. 한 줄 결론

**Cake 의 힘은 기능이 적어서가 아니라, 한 화면에 한 가지만 보여주고 나머지를
뒤로 접어두는 데서 나온다.** 우리 앱은 기능 수는 이미 충분하다 — 고칠 것은
"모든 정보를 같은 층위에 펼쳐놓는 습관"이다.

## 1. Cake 관찰 — 장점 분해

| # | Cake 의 특성 | UX 원리 |
|---|---|---|
| C1 | 홈 = 오늘의 콘텐츠 하나, 한 화면 완결 | 한 화면 = 한 질문 |
| C2 | 지표(스트릭·레벨)는 작은 칩/아이콘으로만 | 신호는 주되 시선은 뺏지 않기 |
| C3 | 상세 통계·설정은 탭/펼침 뒤로 | Progressive disclosure |
| C4 | 카드가 얇다 — 제목 1줄 + 최소 부가 텍스트 | 카드당 정보 3개 이하 |
| C5 | 보기→따라하기→퀴즈가 자동으로 이어짐 | 다음 행동을 고르게 하지 않기 |
| C6 | 이어하기 — 마지막 콘텐츠 1탭 재진입 | 복귀 마찰 제거 |
| C7 | 짧은 세션(1~3분) 단위 마이크로 러닝 | 시작 장벽 최소화 |

## 2. 우리 앱 대조 — 이미 있는 것 / 어긋난 것

| Cake | 우리 현황 | 판정 |
|---|---|---|
| C1 홈 한 화면 | 홈 IA 는 이미 "오늘 하나"(ux-redesign-2026-08) — 그러나 카드 세로 나열로 390px 에서 스크롤 발생 | **어긋남 → 이번에 수정** |
| C2 지표 칩 | Lv·스트릭 칩 있음 — 인사가 text-3xl 로 커서 칩보다 인사가 화면을 먹음 | **어긋남 → 이번에 수정** |
| C3 접어두기 | 잔디 1년·책갈피 설명이 목표 카드에 상시 펼침 | **어긋남 → 이번에 수정** |
| C4 얇은 카드 | 미션 3종이 도장+제목+설명 3행 세로 나열 | **어긋남 → 이번에 수정** |
| C5 자동 이어짐 | 학습 세션 내부는 자동 진행 — 홈→세션 진입은 CTA 1개로 이미 단일 | 유지 |
| C6 이어하기 | 없음 — 덱 이어하기는 라이브러리/학습 탭에서 다시 찾아야 함 | **부재 → P1 기획** |
| C7 마이크로 세션 | "오늘 N개만" 낚싯대 문구가 유사 역할 — 시간 단위 옵션은 없음 | **부분 → P2 기획** |

## 3. 반영 내용 (2026-08-21 — 이번 구현)

모바일 한 화면 원칙: **로그인 홈은 390x844 에서 스크롤 없이 전부 노출**을
성공 기준으로 한다 (ux-redesign-2026-08 §6 의 기준을 강제 조항으로 격상).

| # | 변경 | 파일 |
|---|---|---|
| 1 | 콘텐츠 열 중앙 정렬 (`mx-auto max-w-xl` + 헤더·CTA 가운데) | `app/page.tsx` |
| 2 | 인사 글자 축소 text-3xl→text-xl(모바일)·헤더 여백 축소 | `app/page.tsx` |
| 3 | 잔디 1년·책갈피 설명을 접기(`details`) 기본 닫힘으로 | `DailyGoalCard.tsx` |
| 4 | 미션 세로 3행 → 3열 도장 그리드, 설명은 툴팁으로 | `DailyQuestsCard.tsx` |
| 5 | 카드 패딩 p-4→p-3, 진행바 h-3→h-2.5, 열 gap-7→gap-4 | 홈 카드 전반 |

원칙 (이후 홈에 카드를 추가할 때):
- 홈 카드는 **기본 상태 3행 이하** (제목줄 + 본문 1~2행). 넘치면 접기 또는 탭 이관.
- 상시 카드는 목표·미션 2장까지. 나머지는 조건부 1회 배너만.
