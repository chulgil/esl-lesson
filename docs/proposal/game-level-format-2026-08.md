# 기획: 게임 레벨별 출제 형식 — 영→한/한→영/혼합의 레벨 연동

> 작성: 2026-08-20 · 요구: "게임 콘텐츠에 레벨 설정 — 레벨별 영→한 맞추기,
> 영→영 맞추기, 혼합 설계를 기획적으로 검토, 결과적으로 재미있는 영어 향상"

## 한 줄 결론

**게임의 형식 정체성은 유지하고, 이미 혼합형인 게임(퀴즈로얄·테트리스)의
"방향 비율"을 study_level 로 조정한다** — 새 모드 추가 없이 초급에겐
인지(영→한) 위주, 고급에겐 회상(한→영) 위주로 같은 게임이 다르게 어렵다.

## 현재 형식 실사 (2026-08-20 코드 대조)

| 게임 | 형식 | 방향 | 레벨 연동 |
|---|---|---|---|
| 워드 테트리스 | 탭(선택)+타이핑 | **혼합** — 속도 레벨 2구간마다 영→한(탭) ↔ 한→영(타이핑) 교대 (`direction_for_level`) | 없음 (시간 경과로만) |
| 스피드 퀴즈 로얄 | 4지선다 | **혼합** — 라운드별 50/50 영→한 / 한→영 | 없음 (고정 반반) |
| 리스닝 빙고 | 듣고 탭 | 영음성→영단어 (영→영 인지) | — 형식 고정이 정체성 |
| 받아쓰기 배틀 | 듣고 타이핑 | 영음성→영문 (영→영 회상) | — 형식 고정 |
| 어순 조립 | 칩 배열 | 한→영 (cued recall) | — 형식 고정 |
| 영문 타자 | 복사 타이핑 | 영→영 | — 형식 고정 |
| 데일리 퍼즐 | 글자 추리 | 영→영 | — 형식 고정 |

이미 인지→회상 스펙트럼(영→한 선다 ~ 한→영 타이핑)과 사용자가 말한
영→한/영→영 형식이 모두 존재한다. **없는 것은 "누구에게 어느 비율로"** —
초급(전 사용자 study_level 2)도 한→영 타이핑 라운드를 50% 받는다.

## 검토한 설계안

### A안 (권장) — 혼합형 게임의 방향 비율을 레벨로 조정

인출 위계(recognition→recall, level-format-fit 근거 동일)에 따라 **참가자
최저 study_level** 기준으로 비율 결정 (멀티는 전원이 같은 문제 — 최저
레벨이 이길 수 있어야 "재미있는 향상"):

| 최저 study_level | 퀴즈로얄 영→한 비율 | 테트리스 |
|---|---|---|
| 1 (입문) | 100% (전부 인지) | 한→영(타이핑) 밴드 진입을 2배 늦춤 |
| 2 (초급) | 75% | 〃 |
| 3 (중급) | 50% (현행) | 현행 |
| 4 (고급) | 25% (회상 위주) | 현행 |

- 형식 고정 게임(빙고·받아쓰기·어순·타자·퍼즐)은 **불변** — 스킬 라벨
  (단어/듣기/문장)이 곧 선택지다. 난이도는 풀(내 학습 단어)이 이미 개인화.
- 구현: 서버 문항 생성기에 `study_level` 파라미터 1개 — 신규 화면·설정 0.

### B안 — 게임마다 형식 선택 UI (영→한/한→영/혼합 토글)

보류. 판마다 선택 비용(인지 부하 경고)이 생기고, 멀티에서 방장 선택이
게스트 레벨과 충돌한다. A안 배포 후 "비율이 안 맞다"는 관측이 나오면 방장
오버라이드로 재검토 (P2).

### C안 — 게임 전용 레벨 신설 (게임 난이도 설정 분리)

기각. 학습 난이도(study_level)와 별개 축을 만들면 설정 2곳 관리 —
level-fit-library 의 "이미 있는 축을 쓴다" 원칙 위반.

## 구현 슬라이스

- **P1 (구현 완료 2026-08-20)**: 퀴즈로얄 방향 비율 레벨 연동 —
  `build_questions(en2ko_ratio)` + `min_study_level`(참가자 최저, 폴백 2).
- **P2 (관측 후)**: 테트리스 초급 밴드 지연 · 방장 오버라이드 · 빙고
  고급용 "뜻 음성" 변형(한국어 뜻을 불러주고 영단어 탭 — 역방향 듣기).

## 평가 기준

- 초급 사용자 퀴즈로얄 라운드 정답률 상승 (usage: ReviewLog 아님 — 매치
  stats 의 정답 수) · 게임 재판(다시하기) 횟수 — "재미" 대리 지표
- 가드레일: 고급 사용자 지루함 (4레벨 비율 25% 유지 확인)
