> 요구: "콘텐츠를 초중고 카테고리/태그로 나눠 사용자가 레벨에 맞게 담고, 적절히 추천하는 UX" (2026-08-10 사용자)

**한 줄**: 새 카테고리·태그 필드를 만들지 않는다 — 이미 파생되는 난이도 3단
(초급/중급/고급)과 "아는 표현 %"를 **필터·기본 정렬·온보딩 딥링크**로 연결해,
사용자가 자기 수준의 콘텐츠를 찾고 담게 만든다.

## 용어 확정

"초중고" = **초급/중급/고급** 난이도 3단 — 기존 파생 난이도(`difficulty`,
content-governance.md)와 동일 축. 학령(초등/중등/고등) 태그 해석은 §기각 참조.

## 현재 자산 실사 (2026-08-10 코드 대조)

| 있음 | 없음 (이번 기획) |
|---|---|

| 사용자 학습 난이도 `study_level` 1-4 (설정) | 온보딩에서 "내 레벨 영상" 으로 보내는 동선 |

## 기획 검증 — "레벨을 넣을지"

**결론: 저장 필드(카테고리/태그)는 넣지 않는다.** 근거:

1. **이미 있다** — 난이도는 항목 분포에서 실시간 파생된다 (Simplicity Ladder:
   있는 걸 쓴다). 수동 태그는 등록자가 매번 판단해야 하는 운영 부담 + 파생값과
   어긋나는 드리프트를 만든다.
2. **콘텐츠 11개에 분류 축 추가는 과분류** — 분류가 유용해지는 건 공급이 쌓인
   뒤다. 그때도 파생값이 정본, 수동은 오버라이드.
3. **백오피스 수동 오버라이드 컬럼**(P0-2 보류분)은 "오분류 신고가 실제로 나올
   때" 추가 — 지금은 트리거 없음.

기각 — 학령(초등/중등/고등) 태그: 사용자 수준 축은 난이도로 충분하고, 학령은
소재 취향(kids story 등)이라 별개 축이다. 공급 11개에 두 축은 빈 칸만 늘린다.
초급 키워드 가이드(P0-3)가 이미 소재 성격을 커버 — DAU 성장 후 재검토(P2).

## 사용자 레벨 정의 + 추천 원칙

- **내 레벨** = `study_level` 매핑: 1~2 → 초급, 3 → 중급, 4 → 고급.
  신규 기본(2)이 초급이라 신규 사용자는 자동으로 초급 우선 — 구멍 2의 3일차
  이탈 시나리오("나한텐 어렵다") 방어.
- **추천 원칙 = 이해 가능 입력(i+1)**: 원전 루틴 전제(60~80% 이해)와 동일 —
  `known_ratio` 60~85% 콘텐츠가 최적 학습 구간. 파생 난이도(콘텐츠 절대 난이도)
  + known_ratio(나와의 상대 거리) 둘을 합쳐 "맞음"을 판정한다.

```
fit(콘텐츠) = 난이도 거리 점수 (내 레벨과 같음 2 / ±1단 1 / 그 외 0)
            + known_ratio 점수 (60~85% 2 / 40~60% 또는 85%+ 1 / 그 외 0, null=0)
→ fit 4 = "지금 내 수준" 하이라이트, 정렬은 fit 내림차순 → 최신순
```

## UX 설계 (표면 동결 — 전부 기존 표면 확장, 신규 화면 0)

1. **라이브러리 난이도 필터 칩**: 상단 `[전체] [초급] [중급] [고급]` —
   기본 선택 = **내 레벨**. URL `?level=beginner` 딥링크 (온보딩·추천에서 재사용).
   ux-redesign #5("담은 것" 탭)와 같은 줄에 배치해 탭 도입 시 충돌 없음.
2. **기본 정렬 = 내게 맞는 순** (fit 점수): 카드에 fit 4 는 "지금 내 수준" 칩
   하이라이트. 계산은 클라이언트 — API 가 이미 difficulty·known_ratio 를 반환
   하므로 **신규 백엔드 0**.
3. **온보딩 연결** (P1): 체크리스트 1단계(첫 학습) 앞에 레벨 확인 1탭 —
   기존 `study_level` 설정의 재노출(새 표면 아님). 저장 후 홈 신규 CTA
   ("담은 콘텐츠 0 → 라이브러리")가 `?level=내레벨` 로 딥링크.
4. **레벨 빈 상태 = 공급 신호**: 필터 결과 0이면 "이 레벨 영상이 아직 없어요"
   + 요청 폼(기존) 노출. 백오피스 공급 위젯(P0-B)에 레벨별 부족(초급 0/5)을
   함께 표시 — 필터가 공급 구멍을 숨기지 않고 수요로 되돌린다.

주의: 지금 초급 콘텐츠 0이라 초급 필터는 즉시 빈 상태다 — 이는 이 기획의
버그가 아니라 **공급(P0-3/P0-B) 미이행의 가시화**다. 필터 배포와 초급 5편
확보는 한 세트로 간다.

## 성공 지표

- 신규 사용자 가입 → 첫 담기까지 시간 (필터·정렬 도입 전후)
- 담은 콘텐츠의 fit 분포 — "지금 내 수준" 콘텐츠 담기 비율 상승 여부
- 초급 필터 빈 상태 노출 수 → 콘텐츠 요청 전환 (공급-수요 연결 검증)
- 가드레일: 라이브러리 이탈률 (필터가 선택지를 좁혀 오히려 이탈하면 기본값 재검토)
