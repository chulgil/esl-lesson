# 기획: 듀오링고 전면 분석 — 개인화 학습과학 팩

> 작성: 2026-08-04 · 상태: P1 구현 착수 (이 문서가 스펙 겸용)
> 선행 문서: [retention-plan.md](retention-plan.md) (2026-07-16 — 습관 루프 흡수 완료)
> 목적: 듀오링고를 4계층으로 전면 해부하고, 우리 차별점(유튜브 실전 콘텐츠 + FSRS)을
> 훼손하지 않는 범위에서 학습 효율 장치를 우리 컨셉으로 재해석해 흡수한다.

## 한 줄 요약

듀오링고의 습관 루프는 이미 흡수했다(리텐션 팩 P1). 남은 격차는 **개인화 학습과학**
— 오답 집중 복습·실력 성장 증명·시작점 개인화 — 이며, 우리는 이것을 듀오링고보다
유리한 조건(FSRS 상태 데이터 보유)에서 구현할 수 있다.

## 우리 차별점 (vs 듀오링고) — 지킬 것

| 축 | 듀오링고 | 우리 | 전략 |
|---|---|---|---|
| 콘텐츠 | 합성 문장 (교재식, 실전성 낮음) | **유튜브 실전 발화** — 모든 카드가 원어민 실제 발화 구간과 연결(media) | 최대 차별점. 복습-원본 음성 연계를 계속 강화 |
| 복습 알고리즘 | HLR(half-life regression, 2016) + Birdbrain | **FSRS v5** — 공개 벤치마크에서 HLR 대비 우수, 카드별 stability/difficulty 보유 | FSRS 상태 데이터를 개인화 재료로 활용 (이번 P1) |
| 학습 마찰 | 하트→에너지(2025)로 무료 학습량 제한, 광고 | **마찰 없음** — 제한·광고 없이 학습량은 사용자 설정 | 유지. 에너지류 절대 도입 금지 (아래 기각 근거) |
| 세계관 | 마스코트(듀오) 중심 단일 브랜드 | 노트 x 레고 + 테마 몰 (위장 테마 포함) | 표현은 전부 자체 언어 (저작권 안전선 — retention-plan.md) |

## 듀오링고 메커니즘 인벤토리 (4계층) x 우리 현황

### 1계층 — 학습과학 (이번 기획의 본체)

| 듀오링고 장치 | 원리 | 우리 현황 | 판정 |
|---|---|---|---|
| Birdbrain 개인화 | IRT(문항반응이론) 로지스틱 모델 — 문항 난이도 x 학습자 실력 동시 갱신, 세션 생성기가 정답 확률 기반 문항 선별 | FSRS 가 카드별 stability/difficulty 를 이미 추정 — 동일 목적의 데이터가 **있는데 노출·활용 안 함** | **채택(재해석)** — P1 ①② |
| Mistakes Review (오답 복습) | 세션 말미 오답 재출제 + 오답 보관함에서 집중 연습 | 세션 내 재출제만 있음. 세션이 끝나면 오답은 다음 due 까지 방치 | **채택** — P1 ① 오답 정리 |
| 배치고사 (adaptive placement) | 가입 시 5분 적응형 테스트로 시작 위치 결정 | 신규 기본 초급(2) 고정, 수동 설정만 | **채택** — P2 (설계 후) |
| 짧은 세션 (bite-size) | 3~5분 단위 레슨 | 20문항 페이지 + 오늘의 목표 소량(10/20/50) | 이미 동등 |
| 스페이싱 | 맞출수록 간격 확대 | FSRS — 더 정교 | 이미 우위 |
| Stories/DuoRadio (청해) | 듣기 몰입 콘텐츠 | 라이브러리 A-B 루프 + 학습 중 구간 듣기(media) + 받아쓰기 게임 | 이미 동등 이상 (실전 음성) |

### 2계층 — 습관 루프 (흡수 완료, retention-plan.md)

스트릭+책갈피(동결), 오늘의 미션(일일 퀘스트), 마일스톤 축하, 20시 푸시, 잔디,
XP/레벨, 업적 33종 — **전부 구현됨**. 이번 범위에서 제외.

### 3계층 — 경쟁/소셜

| 장치 | 우리 현황 | 판정 |
|---|---|---|
| 리그 (30인 코호트 승강제, 10디비전) | 주간 친구 리더보드 | **기각 유지** — 코호트당 활성 수십 명 필요. 재검토 트리거: DAU 100+ |
| 친구 퀘스트 (협동 목표) | 친구·관전·채팅 있음, 협동 목표 없음 | P2 후보 (DAU 조건 동일) |
| 시험 랭킹 | 콘텐츠별 시험 + 전체 랭킹 구현됨 | 이미 있음 |

### 4계층 — 수익화 (참고: 우리 포지셔닝 근거)

| 장치 | 듀오링고 | 우리 판정 |
|---|---|---|
| 하트 → 에너지 (2025.7~) | 무료 학습량 제한으로 구독 전환 유도. 정답에도 에너지 차감 — 사용자 반발 대규모 (장기 사용자 이탈 보고 다수) | **기각** — 학습 마찰은 수익화 장치이지 학습 장치가 아님. 오히려 "제한 없는 학습"이 우리 사용자 확보 논거 |
| 구독 (Super/Max) | 무제한 학습 + AI 회화 | 향후 수익화는 **학습을 제한해서 팔지 않는다** — 부가가치형(개인 콘텐츠 등록 한도 확대, 고급 인사이트, 테마)만 검토. 별도 기획 필요 |
| 광고 | 무료 티어 세션 간 광고 | 기각 — 학습 흐름 훼손 |
| 스트릭 복구 판매 | 유료 재화로 스트릭 복원 | 기각 유지 — 책갈피 무료 지급 (주 1회) |

수익성 관점 요약: 듀오링고의 수익은 "학습 제한 해제"를 파는 구조라 학습 효율과
수익이 충돌한다(에너지 반발이 증거). 우리는 실전 콘텐츠 + 무마찰 학습으로 사용자를
모으고, 수익화는 학습량이 아닌 부가가치에서 찾는다 — 이 순서가 초기 사용자 확보에 유리.

## 전략 결론

1. **습관은 끝났다. 이제 개인화다** — 듀오링고 강점 중 미흡수 영역은 Birdbrain 류의
   "약점을 아는 앱". 우리는 FSRS 상태(stability/difficulty/lapses)를 이미 저장하고
   있어서 별도 ML 없이 SQL 로 동등 가치를 낼 수 있다.
2. **실력 증명이 리텐션이다** — 듀오링고의 "배운 단어 수"는 과대 계산(노출=학습)으로
   신뢰가 낮다. 우리는 FSRS stability 로 "**진짜 오래 기억하는 항목 수**"를 증명할 수
   있다 — 실력 체감(말해보카/Speak 벤치마크)과 과학적 근거를 동시에.
3. **표현은 전부 자체 언어** — 명칭·문구·그래픽은 노트 x 레고 세계관으로 재창작
   (retention-plan.md 저작권 안전선 동일 적용).

## P1 — 이번 구현 (개인화 학습과학 팩 2종)

### ① 오답 정리 (weak-focus 복습 모드)

세션이 끝나도 사라지지 않는 오답 노트 — 최근 틀린 카드만 골라 보충 학습한다.

- **선정 기준**: 최근 7일 내 오답(ReviewLog.correct=false) 이력이 있는 카드 중
  suspended 아님 + 가시성 통과 + 활성 레벨 타입. 정렬: stability 낮은 순(없으면 최우선).
- **API**: `GET /api/study/queue?mode=weak` — due 여부 무관 출제, 신규 도입 없음,
  1페이지(20) 한정. 응답 포맷은 기존 큐와 동일 + `mode` 필드.
- **FSRS 처리**: 정상 리뷰로 채점(조기 복습은 FSRS 가 elapsed 반영 — 이득 자연 감쇠).
  별도 "연습 모드" 분리는 기각 — 이중 상태는 복잡도만 늘린다.
- **UI**: 학습 탭에 "오답 정리" 카드 (N개 있을 때만) → `/study/session?mode=weak`.
  홈은 건드리지 않는다 (IA 원칙: 홈=오늘 할 일 하나 — ux-redesign-2026-08.md).
- **카운트**: stats 응답에 `weak_count` 추가 (학습 탭이 이미 stats 를 호출).

### ② 장기 기억 지표 (실력 성장 증명)

"안정적으로 오래 기억하는 항목 N개" — FSRS stability 기반의 정직한 실력 지표.

- **정의**: stability >= 7일 AND state='review' AND suspended 아님 + 가시성 통과.
  UI 라벨: "**장기 기억**" (임계 7일 = 일주일 이상 안 봐도 90% 기억 유지 수준).
- **추이**: 최근 8주 주별 누적 — 카드별 "scheduled_days >= 7 첫 도달" 로그 시각으로
  재생 산출 (스냅샷 테이블 불필요, 소급 가능). stats 에 `long_term: {count, weekly}`.
- **UI**: 학습 탭 카드 컬렉션 섹션에 장기 기억 카운트 + 주간 미니 그래프(브릭 바) +
  "이번 주 +M". 숫자가 늘어나는 경험 자체가 실력 체감 증거.

## 기각 (근거 포함)

- **에너지/하트**: 학습량 제한은 수익화 장치. 2025 에너지 전환은 대규모 반발 —
  무마찰이 우리 포지셔닝이므로 영구 기각.
- **리그**: 유령 리그 역효과 (retention-plan.md 동일). DAU 100+ 에서 재검토.
- **오답 별도 연습 모드(FSRS 미반영)**: 상태 이원화로 복잡도 증가, FSRS 조기 복습
  처리로 충분.
- **Birdbrain 식 별도 ML 모델**: FSRS 상태가 이미 카드 수준 지식 모델 — 중복 투자.
