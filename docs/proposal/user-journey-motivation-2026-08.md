## 한 줄 결론

기능 인벤토리는 이미 두텁다. 얇은 곳은 **감정의 타이밍** — 특히 ① 세션 종료
순간(피크엔드)이 밋밋하고, ② 노력이 실력으로 바뀌는 순간(장기 기억 도달)이
아무 신호 없이 지나가며, ③ 리마인더가 사용자의 생활 리듬과 무관하게 20시 고정이다.
①②를 이번에 반영하고 ③ 이하는 백로그로 잡는다.

## 감사 프레임

저니 8단계를 아래 심리 장치 렌즈로 통과시켰다:
Hook 모델(트리거-행동-가변보상-투자) · Fogg B=MAP · **피크엔드 법칙**(경험 기억 =
절정+마지막) · 자이가르닉 효과(미완성 과제 상기) · 목표 구배(결승선 가까울수록 가속) ·
손실 회피(스트릭) · 부여된 진행(체크리스트) · 정체성 습관("나는 영어 하는 사람") ·
새 출발 효과(월요일 리셋) · 실행 의도("언제·어디서" 구체화).

## P0 — 이번 반영: "노력이 실력이 되는 순간을 보여준다"

### ① 장기 기억 도달 마이크로 축하 (카드 피드백)

정답 처리 결과 카드의 기억 안정도가 처음 7일 임계를 넘는 순간, 피드백 카드에
"장기 기억으로 굳었어요!" 배지를 띄운다.

- **백엔드**: `POST /study/answer` 응답에 `long_term_reached: bool` —
  리뷰 전 stability < 7 이고 리뷰 후 >= 7 이며 정답일 때 true (메모리 비교, 추가 쿼리 0).
  재붕괴 후 재도달도 true (다시 굳힌 것도 성취).
- **프론트**: Feedback 에 초록 배지 1줄. 과장 모달 금지 — 흐름 끊지 않는 마이크로 보상.

### ② 세션 완료 화면 재설계 (피크엔드)

"세션 완료!" 를 오늘의 의미 요약으로 바꾼다. 위에서부터:

1. 정답률 (기존 유지)
2. **오늘 목표 진행 브릭바 + 달성 순간이면 축하 문구** — stats 재조회
   (goal-gradient 마무리, 달성감을 세션 안에서 회수)
3. **이번 세션 장기 기억 +N** (①의 세션 누계) — "실력이 늘었다"는 증거를 엔드에 배치
4. **오답 정리 연결** — 일반 세션 후 `weak_count` > 0 이면 "오답 N개 정리하고 마무리"
   CTA (자이가르닉 — 미완성 잔여를 다음 행동으로). 오답 정리 세션 후에는 "오답을
   정리했어요" 완료 카피 (닫힌 고리의 만족감).
5. 기존 버튼 (이어서 학습 / 어휘망 / 홈)

## 백로그 (P2)

- 장기 기억 성장 카드 공유 (share-image.ts 재사용) — 전파 루프
