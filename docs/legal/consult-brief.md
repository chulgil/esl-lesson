# 법률 자문 의뢰 브리프 — ESL Lessonaza 저작권 검토

> 작성: 2026-07-14 · 용도: 수익화 전 변호사 자문 의뢰 시 그대로 전달
> 내부 사전 검토: [proposal ·specs 문서](../) 및 2026-07-14 저작권 리스크 검토 (AI 보조, 법률 자문 아님)

## 1. 서비스 개요

- **서비스**: esl.lessonaza.app — 유튜브 영상 기반 영어 학습 웹서비스
- **운영 형태**: 개인 운영, 현재 무료 · 회원 소수 (수익화 검토 단계)
- **핵심 기능**: 유튜브 영상에서 학습 항목(단어·숙어·패턴·문장)을 AI 로 추출해
  망각곡선(FSRS) 복습 큐로 제공, 단어 게임(테트리스·퀴즈) 소재로 사용

## 2. 저작물 데이터 흐름 (사실관계)

| 단계 | 내용 | 비고 |
|---|---|---|
| 수집 | 유튜브 자동/수동 자막을 비공식 API(youtube-transcript-api)로 취득 | 영상 파일은 취득·보관하지 않음 |
| 저장 | 영어 스크립트 문장 단위 + AI 한국어 번역을 자체 DB 에 저장 | 번역 = 2차적저작물 해당 가능 |
| 가공 | LLM(Claude)으로 단어·숙어·패턴·문장 추출, 단어 임베딩 생성 | TDM 성격의 분석적 이용 |
| 노출 | 학습 카드·퀴즈·게임 선지로 표시. **전문(全文) 열람 UI 는 제거됨(2026-07-14)** — 재생 중 문장만 동기 표시 | 원본 영상은 항상 유튜브 공식 임베드로 재생 |
| 공유 | 개인 등록분은 본인(+동일 영상 구독자)만. 관리자 승인 공용 콘텐츠는 전 회원 | 공용 승격은 CC 라이선스 게이트 적용(2026-07-14) |

## 3. 기 시행 완화 조치

1. 전문 열람 제거 — 라이브러리는 임베드 재생 + 현재 문장만 표시
2. 공용 승격 CC(크리에이티브 커먼즈) 라이선스 게이트 — 비 CC/미확인은 관리자가
   권리자 허락을 확인한 경우에만 오버라이드
3. `/copyright` 저작권 안내 + 권리자 삭제 요청(Notice & Takedown) 채널 —
   요청 시 지체 없이 삭제, 이의제기 절차 포함
4. 원본 출처(영상 링크) 상시 표시, 영상 재생은 유튜브 임베드 전용(수익 원저작자 귀속)

## 4. 자문 질의 사항

1. **공정이용(저작권법 제35조의5) 해당성**: 위 데이터 흐름(문장 단위 저장·번역·
   학습 카드 변형 이용, 전문 미제공, 원본 시장 비대체) 전제에서 공정이용 항변의
   성립 가능성과 보강 포인트는?
2. **공용 공유 범위**: CC 게이트 하에서도 남는 리스크(예: CC 라이선스 표시 의무
   이행 방식, 비 CC 영상의 관리자 오버라이드 요건)는 어떻게 정비해야 하는가?
3. **번역문 보관**: AI 번역문의 서버 보관·회원 제공이 2차적저작물작성권 침해로
   평가될 가능성과, 문장 단위 제공·삭제 채널 운영이 감경 요소가 되는지?
4. **수익화 영향**: 광고 모델 도입 시 (a) 공정이용 4요소 중 상업성 평가,
   (b) 제140조 단서(영리 목적 비친고죄) 적용에 따른 형사 리스크 변화와
   필요한 추가 조치는?
5. **유튜브 약관**: 비공식 자막 수집의 계약(약관) 위반 노출 수준과, 공식
   Data API/캡션 다운로드(권한 필요) 경로로의 전환 필요성?
6. **OSP 면책(제102조)**: 현재 Notice & Takedown 운영 방식이 온라인서비스제공자
   면책 요건을 충족하는지, 보완할 절차(통지 양식·재게시 절차 등)는?
7. **TDM 입법 대응**: 2026년 3분기 예고된 저작권법 개정(TDM 면책) 방향에서
   본 서비스가 취해야 할 선제 조치(opt-out 존중, 데이터 목록 공개 등)는?
