## 1. 서비스 개요

- **서비스**: esl.lessonaza.app — 유튜브 영상 기반 영어 학습 웹서비스
- **운영 형태**: 개인 운영, 현재 무료 · 회원 소수 (수익화 검토 단계)
- **핵심 기능**: 유튜브 영상에서 학습 항목(단어·숙어·패턴·문장)을 AI 로 추출해
  망각곡선(FSRS) 복습 큐로 제공, 단어 게임(테트리스·퀴즈) 소재로 사용

## 2. 저작물 데이터 흐름 (사실관계)

## 3. 기 시행 완화 조치

1. **회원 등록 경로 전면 제거 (2026-07-27)** — 유튜브 URL·수기 입력 모두 관리자 전용.
   코퍼스가 유한·감사 가능해지고, 모든 항목에 허락 확보가 가능해짐
2. **개별 이용허락 + 증빙 기록 (2026-07-27)** — 비 CC 영상은 권리자명·연락처·
   허락일·허락 범위(자막 저장/번역/변형/상업적 이용)·증빙을 남긴 경우에만 등록.
   파이프라인이 수행하는 이용 3종이 모두 허락되지 않으면 등록 자체를 거부
3. 전문 열람 제거 — 라이브러리는 임베드 재생 + 현재 문장만 표시
4. 공용 등록 CC(크리에이티브 커먼즈) 라이선스 게이트
5. `/copyright` 저작권 안내 + 권리자 삭제 요청(Notice & Takedown) 채널 —
   요청 시 지체 없이 삭제, 이의제기 절차 포함
6. 원본 출처(영상 링크) 상시 표시, 영상 재생은 유튜브 임베드 전용(수익 원저작자 귀속)

## 4. 자문 질의 사항

1. **이용허락 문언의 충분성 (최우선)**: 유튜버로부터 받는 승낙이 이메일 회신
   수준일 때, 자막 복제·**한국어 번역 작성(제22조 2차적저작물)**·학습 항목 변형·
   회원 제공까지 커버하려면 문언에 무엇이 반드시 특정되어야 하는가? 권장 승낙서
   양식이 있는가? 구두·이모지 승낙의 증거력은?
2. **허락의 한계**: 업로더가 영상 내 배경음악·인용 클립·게스트 발언의 권리자가
   아닌 경우, 업로더 허락만으로 서비스가 면책되는 범위는? 실무상 어떤 유형의
   영상을 배제해야 하는가?
3. **공정이용 보충 항변**: 허락을 받지 못한 잔존 콘텐츠(기존 개인 등록분 등)에
   대해 공정이용(제35조의5) 항변의 성립 가능성과 보강 포인트는?
4. **번역문 보관**: AI 번역문의 서버 보관·회원 제공이 2차적저작물작성권 침해로
   평가될 가능성과, 문장 단위 제공·삭제 채널 운영이 감경 요소가 되는지?
5. **수익화 영향**: 광고 모델 도입 시 (a) 공정이용 4요소 중 상업성 평가,
   (b) 제140조 단서(영리 목적 비친고죄) 적용에 따른 형사 리스크 변화와
   필요한 추가 조치는?
6. **유튜브 약관 (저작권과 별개 쟁점)**: 권리자 허락을 받아도 남는 계약 리스크.
   현재 비공식 자막 API + 단어 정렬용 `yt-dlp` 오디오 다운로드를 사용하는데,
   (a) 노출 수준과 실제 제재 사례, (b) **권리자로부터 자막·오디오를 직접 수급**해
   유튜브를 경유하지 않는 방식으로 전환 시 이 리스크가 완전히 해소되는지?
7. **OSP 면책(제102조)**: 회원 등록 경로를 없애 서비스가 직접 이용주체가 된
   구조에서 OSP 면책 논의의 실익이 있는지, Notice & Takedown 운영은 그대로
   유지해야 하는지?
8. **TDM 입법 대응**: 2026년 3분기 예고된 저작권법 개정(TDM 면책) 방향에서
   본 서비스가 취해야 할 선제 조치(opt-out 존중, 데이터 목록 공개 등)는?
9. **CC BY 실무 요건 (2026-07-29 신설, §5 참조)**: (a) 현재 표시 방식(영상
   링크·임베드)이 CC BY 3.0/4.0 저작자표시 요건을 충족하는가, 부족하다면
   최소 보강 항목은? (b) 허위 CC 라벨 영상을 선의로 이용한 경우 민·형사
   책임 범위와, 관리자 큐레이션·스냅샷 기록이 감경 요소가 되는지?
   (c) 자막 추출·번역·학습항목 변형이 CC BY 의 "변경 고지" 의무를
   촉발하는지, 촉발한다면 적정 고지 문구는?

## 5. 유튜브 CCL 근거 재검토 (2026-07-29)

CC 게이트의 법적 근거로 참조되던 2017년 자료(변호사 칼럼: "CC-BY 영상은
저작자표시만 하면 영리 이용 가능")를 현재 기준으로 재검증한 결과.

### 여전히 유효한 부분

- 유튜브는 2026년 현재도 업로드 시 **CC BY(저작자표시) 라이선스 선택 기능을
  제공**하며, 필터 검색·Data API `license=creativeCommon` 조회도 유지된다.
  우리 게이트(contents.youtube_license)의 전제는 유효.
- CC BY 는 저작권상 **영리 이용·변형·2차적저작물 작성을 허용**한다 —
  2017년 자료의 기본 논지는 현재도 성립.
- CC 라이선스는 **기존 이용에 대해 취소 불가(irrevocable)** — 등록 시점에
  라이선스 값·시각을 기록해 두면 이후 업로더가 표준 라이선스로 되돌려도
  그 시점까지의 이용은 적법. 본 서비스는 `contents.youtube_license` +
  `created_at` 으로 스냅샷을 보존 중(증거 가치).

### 2017년 이후 달라진 것 / 자료가 다루지 않는 리스크

| 쟁점 | 내용 | 본 서비스 함의 |
|---|---|---|
| **라이선스 버전 전환** | 2025-08-01 부터 유튜브 CC 옵션이 CC BY **3.0 → 4.0** 으로 변경(비소급). 이전 업로드 영상은 3.0 유지 | 버전별 저작자표시 요건이 다름(4.0 이 더 유연하고, 위반 시 30일 내 시정하면 라이선스 자동 회복되는 치유 조항 보유). 콘텐츠별 버전은 영상 업로드일로 판별 가능 — 표시 형식은 4.0 기준을 따르면 3.0 도 실질 충족 |
| **저작자표시 의무의 구체성** | CC BY 요건 = 저작자명 + 원저작물 링크 + **라이선스 명칭·링크 표시** + 변경 여부 고지. 출처 링크만으로는 불충분할 수 있음 | ~~보강 필요~~ → **1차 반영(2026-07-29)**: 라이브러리 목록·상세에 CC BY 배지 + 라이선스 딥링크(creativecommons.org/licenses/by/4.0) 표시. 원저작자·원본 링크는 유튜브 임베드가 제공. **채널명 텍스트 표기·변경 고지 문구는 잔여 보강 항목** (질의 9(a)(c) 로 확인) |
| **허위 CC 라벨** | 권리 없는 자가 타인 저작물에 CC 를 걸어도 라이선스는 무효. 한국 저작권에는 선의취득이 없어 **선의 이용도 민사 침해는 성립**(형사 고의 부정 가능성만) | CC 표시를 절대 면책으로 오해하지 말 것. 완화: 채널-콘텐츠 동일성 확인 후 등록(관리자 큐레이션), Content ID 클레임 영상은 유튜브가 CC 마킹 자체를 차단(1차 필터), N&T 즉시 삭제 유지 |
| **제3자 삽입물** | CC BY 는 영상 본체에만 미침 — 배경음악·인용 클립·게스트 발언은 별도 권리(§4 질의 2와 동일 구조) | CC 영상이라도 음악 중심·클립 편집형은 배제 |
| **약관과의 이원성** | CC 는 저작권 허락일 뿐, 유튜브 약관의 다운로드 제한은 별도 계약 쟁점으로 잔존 | §4 질의 6 그대로 유효 — CC 영상이어도 yt-dlp 오디오 취득의 약관 리스크는 해소되지 않음 |
| **TDM 면책 미입법** | 2026-07 현재 TDM 면책은 여전히 국회 계류(22대 김태선안, 비영리 한정). 정부는 규제 합리화 과제로 추진 중, 과도기 기준은 문체부 「공정이용 안내서」(2026-02) | §4 질의 8 유지 — CC 게이트가 TDM 불확실성과 무관하게 유효한 안전판이라는 의미가 오히려 강화됨 |

### 결론 (내부 검토 의견 — 법률 자문 아님)

2017년 자료의 핵심 논지(CC BY = 표시 조건부 영리 이용 가능)는 현재도 유효하며
CC 게이트 유지가 타당하다. 다만 (a) **저작자표시를 CC 요건에 맞게 보강**하고
(라이선스 명칭·링크·채널명 — 현재 미충족 가능성), (b) 2025-08 버전 전환(3.0/4.0)을
인지하고, (c) CC 라벨을 허위 라벨·제3자 삽입물까지 면책하는 만능으로 취급하지
않는 것이 전제다. §4 질의 9(신설)로 자문 시 확인 요망.
