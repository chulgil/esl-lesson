# 스펙: 내가 쓰는 말 덱 (My Phrases) — 채팅 발화 기반 학습

> 작성: 2026-08-12 · 개정: 2026-08-14 (언어별 덱 + 100개 순환 보충 + 레벨별 카드).
> 목표: **내가 실제로 자주 쓰는 말**을 학습 재료로 — 유튜브 없는 첫 콘텐츠 유형.
> 남의 문장이 아니라 내 말투가 학습언어로 어떻게 되는지 반복 노출되면
> 실사용 전이가 가장 빠르다 (자기관련성 효과).

## 왜 이 접근인가 (기획)

- 언어 학습 방([chat-language-rooms.md](chat-language-rooms.md))이 (내 원문 ↔
  학습언어 번역) 쌍을 만들고 있다 — **수집 비용 0** (번역 캐시 재사용).
- 원천이 "내 발화"라서 영상·자막이 필요 없다. **기존 항목 파이프라인 합류**가
  설계의 전부:

```
내 채팅(주언어, 방별 target_lang) ── 번역 캐시 쌍 ──> 후보 집계(빈도·길이 필터)
        └─> 언어별 개인 콘텐츠 "내가 쓰는 말 (영어/일본어/…)" (source=chat, private)
                └─> 활성 100개 승격 (빈도순) → LearningItem(sentence) + Occurrence
                        ├─> 복습 큐 (FSRS — **모든 레벨에서 출제**, 형식은 레벨별)
                        ├─> 게임: 타자·어순·받아쓰기 (해당 언어 풀 자동 포함)
                        ├─> 덱 학습 (/study?content_id=) · 시험 · 카드 컬렉션
                        └─> 학습 탭 "내가 쓰는 말" 카드 (언어 탭 · 수집 현황)
```

## 덱 그룹화 — 학습 덱과 분리 (2026-08-14 사용자 결정)

- **학습 탭 "내 덱" 목록은 유튜브 등 콘텐츠 덱만** — chat 덱(source='chat')은
  목록에서 제외한다. 내가 쓰는 말의 유일한 진입점은 전용 섹션.
- **내가 쓰는 말 섹션은 하위 그룹**으로 나눈다: (영어) (일본어) … + **(일반)**.
- **(일반) = 기존 채팅방(개편 후 일반 방) 시절 수집분** — 당시 번역이 있어
  원문·번역 쌍이 유효한 학습카드다. 마이그레이션이 기존 chat 덱을
  `chat_kind='legacy'`, 제목 "내가 쓰는 말 (일반)" 으로 전환한다.
  **신규 수집은 동결** (일반 방 발화는 번역 쌍이 없어 수집 제외 원칙 유지) —
  편집(빼기)·번역 새로고침·학습·게임 풀 합류는 종전대로 동작한다.
- 언어별 덱(아래)은 학습 방 수집분만 — legacy 덱과 별개 행
  (`contents.chat_kind` NULL = 언어별 학습 덱).

## 언어별 덱 (2026-08-14)

- 덱 = `(created_by, source='chat', lang)` 당 1개 — 제목 "내가 쓰는 말 (영어)"
  (LANG_LABELS 파생). 기존 단일 덱은 자기 lang 을 유지하며 제목만 갱신.
- 발화 귀속: 메시지가 속한 **방의 target_lang** (설정값 아님) — ja 방에서 쓴
  말은 ja 덱으로. 방 언어쌍이 곧 수집 문맥이다.
- 후보 조건은 언어 공통: 원문=주언어 감지·4자+·http 제외·빈도 2회+·번역 캐시
  히트(해당 lang)·제외 원장 미포함.

## 활성 100개 순환 보충 (2026-08-14)

| 규칙 | 값 |
|---|---|
| 활성 목표 | 언어당 `ACTIVE_TARGET = 100` 문장 |
| 활성 정의 | 덱 Occurrence 중 **장기기억 미도달**(stability < 7일 — `mastered_item_clause` 와 동일 기준) 항목 |
| 승격 | lazy sync 마다 활성 < 100 이면 부족분만큼 **빈도 높은 순**으로 후보 승격 |
| 장기기억 도달 | 리스트에서 숨김("졸업 N문장" 카운트만) + 게임 풀 제외(기존) + 빈 자리는 다음 sync 때 새 후보로 보충 |
| 정렬 | 목록·출제 우선순위 = 채팅 빈도 내림차순 (`ItemOccurrence.freq`, sync 때 재집계) |
| 후보 부족 | 100 미만이면 그만큼만 — freq 1회 발화를 앞당기지 않는다 (이름값 원칙 유지) |

- `ItemOccurrence.freq`(nullable int, chat 덱 전용) 마이그레이션 추가 —
  스캔 창(최근 2000건) 재집계로 갱신. 창 밖 트레이드오프는 종전(2026-08-13) 명시 유지.
- 기존 100 초과 덱은 강등하지 않는다 (이미 승격된 항목 유지, 신규만 게이트).

## 레벨별 학습카드 (2026-08-14 · 2026-08-18 형식 사다리 개정)

chat 덱의 문장 항목은 **모든 학습 난이도에서 출제**된다 (일반 sentence 는
레벨 4 전용 — chat 덱만 예외. 초급이 자기 덱을 아예 못 보던 갭 해소).
답변 형식이 recognition → cued recall → free recall 사다리를 따른다
([proposal/level-format-fit-2026-08.md](../proposal/level-format-fit-2026-08.md)
— 저레벨 "전체 문장 조립" 단일 형식의 집중력 저하 보고 해소):

| study_level | 형식 |
|---|---|
| 1 (입문) | **뜻 매칭 선다** — 내 원문(주언어) 제시, 같은 덱 문장 4개 중 번역문 선택. 채점 = 기존 choice_ko2en 경로. 덱 문장 4개 미만이면 청크 조립 폴백 |
| 2 (초급) | **청크 조립** — 번역문을 2~4덩이로 균등 분절해 배열 (칩 최대 4개 — WM 4±1 정합, 방해칩 0~1개). 채점 = sentence_assemble 경로 그대로 |
| 3 (중급) | **단어 칩 조립** — 번역문 단어 칩 순서 클릭 (+오답 칩 최대 2개). 채점 = 조립 결과 == 번역문 |
| 4 (고급) | **전체 문장 타이핑** — 기존 sentence 채점(정규화 + Levenshtein ≤ 2 + AI 2차) 그대로 |

- 오답 칩·선지: 같은 덱의 다른 문장에서 샘플링 (없으면 칩 없이 순서 조립만).
- **길이 게이트**: 레벨 1~2 큐(일반·덱 한정·오답 정리)에는 **8단어 이하**
  문장만 출제 — 9단어+ 카드는 레벨 3 진입까지 대기하며 편집 화면에
  "레벨 3부터" 배지(`level_gated`)로 표시된다.
- **혼합 캡**: 레벨 ≤2 **일반 세션** 페이지(20문항)당 문장 카드 최대 5개 —
  선다 리듬 유지. 덱 한정·오답 정리 세션은 캡 없음 (문장 덱을 명시 선택한 것).
- 게임(타자·받아쓰기)은 종전대로 — 이 분기는 학습 세션(/study) 카드에만 적용.

## 문서함(라이브러리) 담기/빼기 (2026-08-18 요청)

chat 덱은 라이브러리 목록에 "내가 쓰는 말" 출처로 노출되고 담기/빼기 토글을
가진다 — **빼기 = 학습 일시정지** (수집분 폐기 아님):

| 규칙 | 동작 |
|---|---|
| 빼기 (DELETE /api/my/contents/{id}) | 구독만 해지 — 큐·게임·카운트에서 제외. **본체는 삭제하지 않는다** (개인 콘텐츠의 "마지막 구독자 이탈 시 본체 삭제" 예외) |
| 재담기 (POST .../subscribe) | 내 chat 덱은 private 여도 허용 (타인 덱은 404). 카드 진행 그대로 복귀 |
| sync 와의 관계 | 자동 구독은 **덱 생성 시 1회만** — lazy sync 가 빼기 의사를 뒤집지 않는다. 빠진 동안에도 수집·편집·번역 새로고침은 계속 |
| 학습 탭 카드 | summary `subscribed` — false 면 학습 버튼 대신 담기 토글 + "지금은 학습에서 빠져 있어요" 안내 |

## 수집 규칙 (노이즈 방어 — 종전 유지)

| 규칙 | 값 | 이유 |
|---|---|---|
| 대상 | 내가 보낸 메시지, 삭제 안 됨, 주언어 감지, 시스템 줄 제외 | 상대 글은 내 말투가 아님 |
| 번역 존재 | ChatTranslation 캐시 히트(방 target_lang) | 추가 비용 없음 원칙 |
| 최소 길이 | 원문 4자 이상 | "ㅋㅋ", "네" 제외 |
| 채택 | 빈도 2회 이상만 | 1회 발화는 아직 '내 말'이 아니다 |
| 제외 | http 포함(링크), 이미지 전용 | 학습 문장이 아님 |
| 상한 | 활성 100 목표 승격 (동기화당 승격 상한 200) | 폭주 방지 |
| 스캔 창 | 최근 메시지 2000건 | 스캔 비용 상한 (다작 유저 트레이드오프, 2026-08-13 명시) |

- **멱등 동기화**: 학습 탭 카드 조회 시 lazy sync. normalized_key get-or-create,
  재실행해도 중복 없음. 실명은 평범한 이름으로 치환(anonymize, 종전).
- **편집(빼기)**: 문장 빼기 = Occurrence 삭제 + 제외 원장(이중 키) — 재동기화에도
  안 돌아옴 (종전). 빠진 자리는 다음 sync 보충 대상.

## 데이터 모델

- `contents`: source='chat' 이 **유저당 언어별 1개** (created_by+source+lang —
  코드 레벨 get-or-create, 기존 단일 덱과 호환).
- `ItemOccurrence.freq`: 채팅 빈도 (chat 덱만 사용, 그 외 NULL).
- 항목: `LearningItem(sentence, en_text=학습언어 번역문, ko_text=내 원문)` —
  필드명은 역사적 유산 (chat-translation.md 동일).

## API·화면

| 표면 | 내용 |
|---|---|
| GET /api/study/my-phrases?lang= | lazy sync 후 {content_id, lang, total, active, graduated, added_now, recent[5]}. lang 생략 = learning_langs[0]. **lang='legacy' = (일반) 덱** (sync 없음, added_now=0) |
| GET /api/study/my-phrases/items?lang= | 편집용 활성 목록 (freq 내림차순, freq·장기기억 여부 포함) + graduated 카운트 |
| POST /api/study/my-phrases/refresh | 번역 품질 새로고침 (lang 파라미터, 종전 동작) |
| DELETE /api/study/my-phrases/{item_id} | 문장 빼기 (언어 무관 — 항목이 속한 내 chat 덱에서) |
| 학습 탭 카드 | "내가 쓰는 말" — **하위 그룹 칩 (영어)(일본어)…+(일반)** (legacy 덱이 있고 항목>0 일 때만 (일반) 노출) · 활성 N/100 · 졸업 M · 최근 추가 · "이 덱으로 학습". (일반) 탭엔 "새 문장은 학습 방에서 모여요" 안내. 0개면 학습 방 만들기 안내. **기본 탭 폴백**: 첫 학습언어 덱이 0문장이고 (일반) 수집분이 있으면 (일반)을 자동 선택 — 사용자가 탭을 직접 고르기 전까지만 (2026-08-18 "덱 학습이 안 보인다" 보고: 언어 방 도입 전 사용자는 수집분 전체가 (일반)에 있어 빈 언어 탭이 기본이면 학습 버튼이 숨는다) |
| /study/phrases | 언어 탭 + 빈도 배지("N회") + 졸업 문장 접힘 목록 + 빼기 |

## 성장 루프 (기획 의도)

학습 방에서 채팅할수록 → 언어별 내 말투 덱이 자라고 → 복습·게임에서 "어제 내가
한 말"이 나온다 → 다음 채팅에서 학습언어로 직접 써볼 동기 → 다시 번역·수집.
장기기억에 정착한 말은 조용히 졸업하고 새 말이 그 자리를 채운다 — 덱은 항상
"지금 익히는 중인 내 말 100문장"이다.
