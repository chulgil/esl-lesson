# 스펙: 내가 쓰는 말 덱 (My Phrases) — 채팅 발화 기반 학습

> 작성: 2026-08-12. 목표: **내가 실제로 자주 쓰는 말**을 학습 재료로 —
> 유튜브 없는 첫 콘텐츠 유형. 남의 문장이 아니라 내 말투가 학습언어로
> 어떻게 되는지 반복 노출되면 실사용 전이가 가장 빠르다 (자기관련성 효과).

## 왜 이 접근인가 (기획)

- 채팅 자동번역(chat-translation.md)이 이미 (내 원문 ↔ 학습언어 번역) 쌍을
  만들고 있다 — **수집 비용 0** (번역 캐시 재사용, 추가 LLM 호출 없음)
- 유튜브 파이프라인(자막→추출)과 달리 원천이 "내 발화"라서 영상·자막이
  필요 없다. 대신 **기존 항목 파이프라인에 합류**시키는 것이 설계의 전부:

```
내 채팅(주언어) ── 번역 캐시 쌍 ──> 후보 수집(빈도·길이 필터)
        └─> 개인 콘텐츠 "내가 쓰는 말" (source=chat, private, 유저당 1개)
                └─> LearningItem(sentence, en=번역문, ko=내 원문) + Occurrence
                        ├─> 복습 큐 (FSRS 자동 편입 — 기존 신규 도입 예산)
                        ├─> 게임: 타자연습·어순 조립·받아쓰기 (문장 풀 자동 포함)
                        ├─> 덱 학습 (/study?content_id=) · 시험 · 카드 컬렉션
                        └─> 학습 탭 "내가 쓰는 말" 카드 (수집 현황·바로 학습)
```

## 수집 규칙 (노이즈 방어)

| 규칙 | 값 | 이유 |
|---|---|---|
| 대상 | 내가 보낸 메시지, 삭제 안 됨, 주언어 감지 | 상대 글은 내 말투가 아님 |
| 번역 존재 | ChatTranslation 캐시 히트(학습언어) | 번역 없는 문장은 쌍이 안 됨 — 추가 비용 없음 원칙 |
| 최소 길이 | 원문 4자 이상 | "ㅋㅋ", "네" 제외 |
| 채택 | 빈도 2회 이상 **또는** 6자 이상 | "자주 쓰는 말" 우선 + 한 번 썼어도 문장다우면 채택 |
| 제외 | http 포함(링크), 이미지 전용 | 학습 문장이 아님 |
| 상한 | 동기화당 후보 200개 | 폭주 방지 |

- **멱등 동기화**: 학습 탭 카드 조회 시 lazy sync (theme_rewards 패턴).
  normalized_key(번역문 lower) get-or-create — 전역 항목 dedup 과 동일 원칙,
  이미 있으면 Occurrence 만 연결. 재실행해도 중복 없음
- **편집(빼기)**: /study/phrases 에서 문장 빼기 — Occurrence 삭제 + 제외
  원장(phrase_exclusions, 원문 정규화 키)에 기록되어 **재동기화에도 돌아오지
  않는다** (2026-08-12 요청). 복습 큐·게임 풀에서도 가시성 규칙상 함께 제외

## 데이터 모델 (신규 테이블 없음)

- `contents.source` CHECK 에 `'chat'` 추가 (마이그레이션) — 유저당 1개
  (created_by=유저, visibility=private, status=ready, title="내가 쓰는 말",
  lang=학습언어). 본인 자동 구독(ContentSubscription)
- 항목: `LearningItem(item_type="sentence", en_text=학습언어 번역문,
  ko_text=내 원문)` — en/ko 필드명은 역사적 유산 (chat-translation.md 동일)
- 프라이버시: private 콘텐츠 + 본인만 구독 → 가시성 규칙상 본인 외 노출 없음

## 게임 적용 (자동)

문장 게임 3종(타자연습·어순 조립·받아쓰기)은 `visible_item_clause` 기반
문장 풀을 쓰므로 **코드 수정 없이** 내 표현이 출제된다. 받아쓰기 TTS 는
번역문(학습언어) — edge-tts 로 무료. 단어 게임(퀴즈·빙고·테트리스)은 단어
추출이 없어 미포함 — 후속(P2): 내 문장에서 핵심 단어 추출해 단어 풀 합류.

## API·화면

| 표면 | 내용 |
|---|---|
| GET /api/study/my-phrases | lazy sync 후 {content_id, total, added_now, recent[5]} |
| 학습 탭 카드 | "내가 쓰는 말" — 수집 문장 수·최근 추가 미리보기·"이 덱으로 학습"(기존 /study?content_id= 라우트)·게임 자동 출제 안내. 0개면 채팅 자동번역 켜기 안내 |

## 성장 루프 (기획 의도)

채팅을 할수록 → 내 말투 덱이 자라고 → 복습·게임에서 "어제 내가 한 말"이
나온다 → 다음 채팅에서 학습언어로 직접 써볼 동기 → 다시 번역·수집.
채팅(사회적 동기)과 학습(반복)이 한 루프로 닫힌다.
