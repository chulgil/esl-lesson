# 스펙: UI 디자인 시스템 — 노트 x 레고

> 최종 검증: 2026-07-30 (코드 대조 완료)
> 2026-08-04 부분 갱신(코드 대조): 테마 6종·표면 은유·메뉴 라벨·홈 IA

컨셉: **공책(노트) 위에 레고 브릭을 쌓으며 공부하는 느낌**. 배경/레이아웃은 노트(줄노트, 종이 질감, 손글씨 헤딩), 인터랙션 요소(버튼, 카드, 진행도)는 레고(원색 브릭, 스터드 도트, 딸깍 맞물리는 애니메이션).

**학교 ↔ 학원 분리** (2026-08-04): 학교수업 하나가 칠판과 갱지를 겸해 정체가 흐렸다.
칠판은 학교수업(교실에서 선생님이 쓴다), 갱지는 학원(모의고사를 푼다)으로 나눴다.
칠판은 **표면**(문제 카드·답안지·게임 보드)이 담당하고 **배경은 교실 벽** — 화면 전체를
어둡게 덮으면 장시간 학습에 부담이라 어두운 면을 표면으로 한정한다.

접근 정책(free/restricted)은 이 표에 두지 않는다 — 백오피스에서 바뀌는 값이라
문서가 곧 낡는다. 정본은 `backend/app/services/themes.py THEME_ACCESS` +
`theme_settings` 오버라이드, 설명은 [theme-mall.md](theme-mall.md).
2026-07-30 전환 이후 **기본 무료는 note 하나**이고 나머지는 업적 보상·이벤트 지급으로 열린다.

**은유는 테마마다 배타적** (2026-08-04): 두 테마가 같은 물체(칠판·시트·블록판)를
쓰면 화면에서 테마 구분이 사라진다. 헤냥이가 학습·시험 표면에서 칠판을 쓰고 있어
고양이 세계관이 그 화면에서만 끊겼던 사고에서 확정 — **칠판은 학교수업만 쓴다**
(게임 보드 배경·칠판그린 토큰·교실 벽시계·표제 밴드).

접근 정책의 서버 단일 근거는 `backend/app/services/themes.py THEME_ACCESS` —
미허용 테마는 설정에서 잠기고 AppNav 전역 가드가 세션마다 원복한다 (theme-mall.md).

```

+--------+
```

대시보드 지표 표기 규칙 (2026-08-03 수정):
- **잔디 = 최근 1년(53주) GitHub 식**: 열=주, 행=요일(행 라벨 월·수·금), 상단 월 라벨, 좁은 화면은 가로 스크롤 + 진입/리사이즈 시 오른쪽 끝(오늘)으로 이동. 오늘은 링 강조, 책갈피 날은 노랑. 날짜 키는 **KST 고정**(`Intl` `Asia/Seoul`, KST 오늘을 UTC 자정으로 앵커링해 달력 산술) — 서버 `stats.daily` 가 KST 날짜라 UTC/로컬로 만들면 KST 00~09시에 하루씩 밀린다. 서버는 이 뷰에 맞춰 `daily` 를 **400일** 내려준다
- **브릭 타워 = 비율**: 8칸이 `available_items` 100%. 칸 수를 카드 수로 세면 8개 이상이 전부 꽉 찬 막대가 되어 `512/20000` 과 `8/8` 이 같아 보인다. 칸 옆에 `보유/전체 (%)` 병기
- **컬렉션 분자 = 한 번이라도 푼 카드**(`reps > 0`): 큐가 도입만 한 새 카드를 세면 담은 콘텐츠를 꺼내보는 순간 영구 100% 라 지표가 죽는다
- **홈 1차 행동은 하나**: 라이브러리·채팅·게임 브릭은 전역 5탭과 중복이라 홈에서 제거 (2026-08-03). 홈의 브릭은 "오늘의 학습 시작" 하나
- **콘텐츠 0이면 학습이 아니라 라이브러리로** (2026-08-03): 담은 콘텐츠가 없으면 학습 큐 자체가 만들어지지 않는다. `stats.levels` 의 `available_items` 가 전부 0이면 홈 브릭을 "라이브러리에서 콘텐츠 담기"로 바꾼다 — 기존엔 "새 카드 만나러 가기"가 빈 세션으로 들어갔다
- **오늘(홈) ↔ 누적(학습) 분리** (2026-08-03): 카드 컬렉션은 누적 자산 지표라 홈이 아니라 학습 탭에 둔다 (`components/study/CardCollection.tsx`). 홈과 `/study` 가 같은 지표를 각각 갖고 있으면 "어느 쪽이 진짜 시작 버튼인지"를 매번 판단해야 한다 — 중복 대시보드 정리는 [ux-redesign-2026-08.md](../proposal/ux-redesign-2026-08.md) 기획의 1차 반영분

### 홈 모바일 한 화면 원칙 (2026-08-21 — Cake 벤치마크)

**로그인 홈은 390x844 에서 스크롤 없이 전부 노출**된다 (ux-redesign §6 성공 기준을
강제 조항으로 격상, 근거는 [cake-benchmark-2026-08.md](../proposal/cake-benchmark-2026-08.md)).

- **콘텐츠 열 중앙 정렬**: 홈 `section` 은 `mx-auto max-w-xl` + 헤더·CTA 가운데 정렬.
  학습·라이브러리·게임·설정도 콘텐츠 열(`max-w-4xl`/`max-w-lg`)을 `mx-auto` 로 중앙
  배치한다 — 배경(괘선)은 전폭 유지, 열만 중앙.
- **인사 타이포 축소**: 홈 인사는 `text-xl`(모바일)/`text-2xl`(sm+) — 모바일 한 줄.
- **Progressive disclosure**: 잔디 1년 달력·책갈피 설명은 오늘의 목표 카드의
  접기(`details`) 안, 기본 닫힘. 잔디는 열릴 때만 마운트한다 (오늘 위치 자동
  스크롤 이펙트가 접힌 폭 0 상태에서 돌면 무의미).
- **미션 3열 도장 그리드**: 세로 3행 나열 금지 — 도장+제목+진행(`n/N · +XP`)의
  3열 1행, 상세 설명은 `title` 툴팁.
- **홈 카드 예산**: 상시 카드는 목표·미션 2장까지, 카드 기본 상태는 3행 이하
  (제목줄 + 본문 1~2행). 넘치면 접기 또는 학습 탭 이관. 조건부 배너(성적표·복귀
  감사·학습 중 친구)는 1회성/일시 노출만 허용.
- **이어하기 줄** (2026-08-21 C6): 진행 중(1~5단계) 정복 루틴이 있으면 CTA 아래
  얇은 1줄(`ResumeRoutineCard`) — 최다 진행 1개만, 없으면 렌더 안 함. 카드가
  아니라 줄이므로 카드 예산에 세지 않는다.

| 요소 | 적용 |

| 하단 탭바 (`AppNav`) | `pb-[env(safe-area-inset-bottom)]` — 배경은 바닥까지, 탭은 위로 |

| 단계 | 완료 판정 | 링크 |
|---|---|---|
| ① 첫 학습 시작하기 | `stats.levels` 의 `cards` 합 > 0 | `/study/session` |
| ② 영상 한 편 정복 시작하기 (구 '갈아 넣기' — 2026-08-10 사용자 피드백으로 개칭) | `/api/study/decks` 의 덱 중 `routine_done > 0` | `/library` |
| ③ 복습 리마인더 시각 정하기 | `/api/settings` 의 `push_subscribed` (내 기기 구독 1개 이상 — 서버 파생) | `/settings` |

- **③ 은 VAPID 미설정 환경에서 숨긴다** — `/api/push/config` 의 `enabled=false` 면 달성 불가능한 단계라 영구 미완료로 남는다 (관리자 전용이 된 "영상 등록" 단계를 2026-07-28 에 제거한 것과 같은 이유).
- **친구 추가는 3단계 완료 후에만 노출** — 학습 핵심이 아닌 항목이 첫 주 계약을 흐린다.
- **레벨 확인 1탭 (2026-08-10 — level-fit-library P1)**: 단계 목록 위에 "내 레벨: [초급][중급][고급]" 칩 — `study_level` PATCH (초급=2/중급=3/고급=4, 입문 1 은 초급 밴드로 표시·같은 밴드 재탭은 no-op). 라이브러리 기본 필터·게임 추천이 이 값을 따르므로 첫 학습 전에 확인시킨다. 단계(완료 판정)가 아니라 설정 재노출이다.
- 헤더에 `/method` 링크. 전 단계 완료 시 체크리스트 자체가 사라진다.
- **조건부 노출 (2026-08-10 ux-redesign #8)**: 카드 0장(진짜 신규) 또는 가입 3일 이내만 홈에 노출 — 그 뒤엔 미완료 단계가 남아도 숨긴다 (`/api/me` `created_at` 기준). 평상시 홈 = 데일리 루프만. 스트릭 마일스톤 축하도 같은 취지로 모달 → 하단 토스트(10초 자동 소멸, 공유 버튼 유지).

`/method` — "이 앱이 영어를 늘리는 방법" (비로그인 열람 가능, 정적):

- **인풋 → 전환 → 아웃풋 → 증거** 4고리 카드 + 첫 주 기대치("하루 15개 복습 + 영상 1편, 1개만 해도 스트릭은 이어져요") + `학습 시작` 브릭.
- 카피는 랜딩(`components/landing/Showcase.tsx`) 재사용 — 로그인 전후가 다른 이야기를 하면 방법을 믿을 근거가 흩어진다. 신규 서사 창작 금지.
- 진입점: 체크리스트 헤더, 라이브러리 빈 상태(콘텐츠 0 — 담을 게 없는 순간이 방법을 읽을 유일한 여유).

## 모션 원칙

| 상황 | 모션 | 시간 |
|------|------|------|
| 브릭 스냅(정답/진행) | scale 1.06 → 1 + 살짝 바운스 | 180ms |
| 오답 흔들림 | translateX +-6px 3회 | 300ms |
| 카드 전환 | 다음 카드가 아래에서 슬라이드 + 기존 카드 위로 넘김 | 250ms |
| 페이지 전환 | 노트 페이지 넘김 느낌의 가벼운 fade+slide | 200ms |

- `prefers-reduced-motion` 존중: 흔들림/바운스 제거, fade만.
- 라이브러리: CSS transition 우선, 복합 시퀀스만 framer-motion.

## 반응형/접근성

- 모바일 우선 (학습은 폰에서 주로 발생). 브레이크포인트: 640 / 1024.
- 퀴즈 보기 브릭은 모바일에서 2x2 그리드, 터치 타겟 44px 이상.
- 키보드: 선다 1-4 숫자키, 입력형 Enter 제출. 포커스 링은 ink 색 점선 (노트에 연필 테두리 은유).
- 명도 대비: 본문 4.5:1 이상 확보 (brick-yellow 위 텍스트는 ink 사용, 흰색 금지).
