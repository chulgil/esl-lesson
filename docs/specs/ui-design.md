# 스펙: UI 디자인 시스템 — 노트 x 레고

> 최종 검증: 2026-07-30 (코드 대조 완료)

컨셉: **공책(노트) 위에 레고 브릭을 쌓으며 공부하는 느낌**. 배경/레이아웃은 노트(줄노트, 종이 질감, 손글씨 헤딩), 인터랙션 요소(버튼, 카드, 진행도)는 레고(원색 브릭, 스터드 도트, 딸깍 맞물리는 애니메이션).

## 무드/은유 매핑

| UI 요소 | 은유 | 표현 |
|---------|------|------|
| 페이지 배경 | 노트 내지 | 미색(#FDFBF3) + 가로 괘선(연한 하늘색) + 좌측 빨간 마진선 |
| 섹션 헤딩 | 손글씨 메모 | 손글씨체 + 형광펜 하이라이트(노랑 반투명 밑칠) |
| 버튼/CTA | 레고 브릭 | 원색 브릭 + 상단 스터드 2-4개 + 아래 두꺼운 그림자(3D 단차) |
| 퀴즈 카드 | 노트에 붙인 인덱스 카드 | 흰 카드 + 마스킹테이프 조각 + 살짝 기운 회전(-1~1deg) |
| 진행바 | 브릭 쌓기 | 문항당 브릭 1개가 가로로 스냅되며 채워짐 |
| 레벨 표시 | 브릭 색상 | 레벨 1=빨강, 2=노랑, 3=파랑, 4=초록 |
| 통계/스트릭 | 스티커/도장 | 날짜 히트맵을 스티커 칸으로 |

### 전역 테마 (2026-07-13 추가 — 설정 > 테마)

위 토큰은 **노트(기본) 테마** 값. `html[data-theme]` 로 토큰 세트를 통째로
오버라이드해 앱 전체(배경 패턴·버튼·게임 보드)가 함께 바뀐다. localStorage
`app.theme` 저장, 페인트 전 부트 스크립트로 FOUC 방지 (`frontend/src/lib/theme.ts`).

테마 5종 (`APP_THEMES` — key/label/스와치가 단일 근거):

| 테마 key | 라벨 | 컨셉 | 접근 |
|------|------|------|------|
| note (기본) | 노트 | 줄노트 괘선 + 마진선, 클래식 레고 원색 | free |
| candy | 캔디 | 버블 도트, 파스텔 (핑크/민트) | free |
| lego | 레고 | 스터드 도트 격자, 클래식 원색 | free |
| cat | 헤냥이 | 고양이 컨셉 | **restricted** — 지급받은 계정만 ([theme-mall.md](theme-mall.md)) |
| excel | 오피스 | 스프레드시트 위장 (chat.md 위장 테마와 연동) | free |

접근 정책의 서버 단일 근거는 `backend/app/services/themes.py THEME_ACCESS` —
미허용 테마는 설정에서 잠기고 AppNav 전역 가드가 세션마다 원복한다 (theme-mall.md).

### 브릭 컴포넌트 (핵심 시그니처)

```
 (o) (o)      <- 스터드 (윗면 도트, radial-gradient)
+--------+
| 학습 시작 |   <- 본체 (원색, 둥근 모서리 6px)
+--------+
 ========     <- 하단 단차 (box-shadow 0 6px 0 brick-shadow)
```

- hover: 살짝 떠오름 (translateY -2px, 그림자 8px)
- active(클릭): 눌림 (translateY +4px, 그림자 2px) + "딸깍" 스냅 느낌 (100ms)
- 비활성: 채도 제거 + 스터드 숨김

## 페이지별 적용

### 서비스 (esl)

| 화면 | 연출 |
|------|------|
| 로그인 | 노트 표지 컨셉 (겉표지 질감 + 네임태그에 "Google로 시작하기" 브릭) |
| 대시보드 | 노트 펼침. "오늘의 목표" 카드(진행바 + **이번 달 잔디 달력**) + 레벨별 브릭 타워 + 스트릭 스티커 판 |
| 학습 세션 | 상단 브릭 진행바, 중앙 인덱스 카드(문항), 하단 보기 브릭 4개(선다) 또는 단어 칩(조립) 또는 입력란(노트 괘선 위 필기 느낌) |
| 정답 피드백 | 브릭이 진행바에 스냅 + 초록 반짝. 오답: 카드 좌우 흔들림 + 빨간 밑줄 diff |
| 세션 완료 | 쌓인 브릭 타워 + 도장 쾅(오늘 완료) + 통계 |
| 게임 | 테트리스 이펙트 우선, 프레임(보드 테두리/버튼)만 노트x레고 유지 — [word-tetris.md](word-tetris.md) |

대시보드 지표 표기 규칙 (2026-08-03 수정):
- **잔디 = 이번 달 달력**: 요일 헤더(일~토) + 1일~말일, 1일 앞칸은 지난달 말일(흐리게), 오늘은 테두리 강조. 날짜 키는 **KST 고정**(`Intl` `Asia/Seoul`) — 서버 `stats.daily` 가 KST 날짜라 UTC/로컬로 만들면 KST 00~09시에 하루씩 밀린다
- **브릭 타워 = 비율**: 8칸이 `available_items` 100%. 칸 수를 카드 수로 세면 8개 이상이 전부 꽉 찬 막대가 되어 `512/20000` 과 `8/8` 이 같아 보인다. 칸 옆에 `보유/전체 (%)` 병기

### 전역 내비게이션 (2026-07-28 개편 — `components/nav/AppNav.tsx`)

- **이동 5탭**: 홈·학습·라이브러리·채팅·게임 — 데스크톱 헤더 좌측 / 모바일 하단
  고정 탭바. "내 콘텐츠" 탭은 관리자 전용 사양 전환으로 제거, 채팅을 주 메뉴로 승격.
- **모바일 상단 미니바** (`mobile-topbar`): 로고·알림 벨·채팅·설정 — 하단 탭바는
  이동 전용, 계정성 메뉴는 상단으로 분리.
- **프로필 아바타 메뉴** (`ProfileMenu.tsx`): 설정·로그아웃 등 계정성 항목 드롭다운.
- **배지 일원화**: 알림+채팅 unread 는 벨 배지 하나로 합산 ([notifications.md](notifications.md)).
- **데스크톱 헤더 접힘**: 접으면 테마별 손잡이만 남음 (종이 계열 = 책갈피 리본,
  오피스 = 리본 탭). hover 피크 / 클릭 고정 해제, localStorage `app.nav-collapsed`.
- 게임 플레이 중 `body.game-focus` 로 탭바·마스코트 숨김 (daily-puzzle.md 등).

### 백오피스 (`/admin`)

- 동일 토큰을 쓰되 **장식 최소화** (손글씨 헤딩/테이프 정도만). 테이블/폼은 밀도 높은 실무형 — 관리자는 효율이 우선.

## 모션 원칙

| 상황 | 모션 | 시간 |
|------|------|------|
| 브릭 스냅(정답/진행) | scale 1.06 → 1 + 살짝 바운스 | 180ms |
| 오답 흔들림 | translateX +-6px 3회 | 300ms |
| 카드 전환 | 다음 카드가 아래에서 슬라이드 + 기존 카드 위로 넘김 | 250ms |
| 페이지 전환 | 노트 페이지 넘김 느낌의 가벼운 fade+slide | 200ms |

- `prefers-reduced-motion` 존중: 흔들림/바운스 제거, fade만.
- 라이브러리: CSS transition 우선, 복합 시퀀스만 framer-motion.

## 반응형/접근성

- 모바일 우선 (학습은 폰에서 주로 발생). 브레이크포인트: 640 / 1024.
- 퀴즈 보기 브릭은 모바일에서 2x2 그리드, 터치 타겟 44px 이상.
- 키보드: 선다 1-4 숫자키, 입력형 Enter 제출. 포커스 링은 ink 색 점선 (노트에 연필 테두리 은유).
- 명도 대비: 본문 4.5:1 이상 확보 (brick-yellow 위 텍스트는 ink 사용, 흰색 금지).

## 구현 메모

- 토큰은 `frontend/src/app/globals.css`의 `@theme` (Tailwind 4)으로 1곳 정의.
- 브릭/카드/칩/진행바는 공용 컴포넌트(`src/components/brick/*`)로 — 페이지별 재구현 금지.
- 괘선 배경은 CSS repeating-linear-gradient (이미지 에셋 불필요).
