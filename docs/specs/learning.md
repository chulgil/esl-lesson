# 스펙: 학습 시스템 (FSRS 간격 반복 + 레벨 1-4 퀴즈)

> 최종 수정: 2026-07-11

안키와 동일한 원리의 간격 반복(Spaced Repetition)을 FSRS 알고리즘으로 구현한다. 사용자가 "잊어버릴 만한 시점"에 항목이 복습 큐에 자동으로 나타나고, 레벨별 퀴즈 형식으로 검사한다.

## FSRS 스케줄링

### 원리 (비유)

기억은 방수 코팅과 같다 — 코팅(복습)을 갓 했을 때는 물(망각)이 스며들지 않지만 시간이 지나며 벗겨진다. FSRS는 항목마다 "코팅이 벗겨지는 속도(stability)"와 "표면 재질(difficulty)"을 추정해, 기억률이 목표치(기본 90%)로 떨어지는 순간을 다음 복습일로 잡는다.

### 구현

- 라이브러리: py-fsrs (FSRS v5 기본 파라미터로 시작).
- 카드 상태: `new → learning → review`, 실패 시 `relearning` (FSRS 표준).
- 목표 기억률: `user_settings.desired_retention` (기본 0.90).
- 파라미터 개인화: review_logs가 1,000건 이상 쌓이면 FSRS optimizer 재학습 배치를 도입한다 (페이즈 1 범위 외, 로그 스키마는 처음부터 optimizer 호환으로 설계 — [database.md](../architecture/database.md) review_logs 참조).

### 레이팅 산출 (퀴즈 결과 → FSRS rating)

채점 직후 **안키식 4버튼**을 노출한다 (2026-07-11 개정 — 사용자 요구). 각 버튼에는 FSRS가 그 자리에서 계산한 **예상 다음 간격**이 표시된다 (예: 다시 15분 / 어려움 1일 / 알맞음 3일 / 쉬움 8일 — 카드 상태에 따라 변동).

피드백 화면의 정답 옆 **[단어 정보]** 버튼(단어·숙어만)으로 뉘앙스·유사단어·예문 카드를 연다 (2026-07-13 — [word-insight.md](word-insight.md)).

- 자동 산출 등급(아래 표)이 기본으로 강조되며, 버튼이 곧 "다음" 역할 — 누르면 해당 등급으로 확정 후 다음 문항 (안키와 동일 흐름).
- 다른 등급을 누르면 직전 스냅샷에서 재평가(`POST /study/rate`) 후 진행.
- **모르겠어요 버튼**: 답을 입력하지 않아도 정답을 확인하고 등급을 고를 수 있다 (오답=다시 기본).
- 간격 산출은 안키와 같은 원리 — FSRS가 카드의 기억 안정도에서 등급별 다음 복습 시점을 계산 (하드코딩 아님).

자동 산출(기본 강조 등급):

| 퀴즈 결과 | rating |
|-----------|--------|
| 오답/모르겠어요 | 1 (다시) — 같은 세션 내 재출제 |
| 정답, 응답시간 > 타입별 기준(선다 12s / 입력 40s) | 2 (어려움) |
| 정답, 정상 응답 | 3 (알맞음) |
| 정답, 응답시간 < 타입별 기준(선다 4s / 입력 15s) 연속 2회째 | 4 (쉬움) |

## 레벨별 학습 설계 (2026-07-11 추가 — 학생 수준별)

오늘의 학습은 학생의 **학습 난이도(study_level 1-4)** 로 구성한다. 낮을수록 짧은 항목 + 보기 선택 위주, 문장 타이핑은 고급에서만.

| 난이도 | 활성 항목(레벨) | 출제 방식 |
|--------|----------------|-----------|
| 1 입문 | 단어 | 4지선다 (선택) |
| 2 초급 (신규 기본) | 단어 + 숙어 | 선다 / 문맥 빈칸 (선택) |
| 3 중급 | + 패턴 | + 칩 조립 (선택) |
| 4 고급 | + 문장 | + 문장 직접 입력(타이핑) |

- **신규 사용자 기본 = 초급(2)**: 타이핑 없이 단어·숙어를 보기 선택으로 시작해 진입 장벽을 낮춘다.
- 설정에서 난이도를 올리면 상위 항목이 추가된다. `levels_enabled = 1..study_level` 로 파생.
- 문장(레벨4) 외 모든 유형은 선택/조립 — 초보자가 타이핑 부담 없이 매일 학습.

## 힌트 타이머 (2026-07-11 추가)

무응답이 `hint_delay_seconds`(설정, 기본 10초, 0=끄기) 지나면 힌트가 켜진다. 켜진 뒤에는 **시간이 아니라 입력 진행에 따라 다음 한 단어만** 노출한다(2026-07-11 개정) — 선다: 정답 보기 강조 / 패턴: 지금까지 고른 다음 칩 하나 강조 / 영작: 맞게 친 단어 다음의 한 단어만 표시. 전체를 한꺼번에 보여주지 않아 순서를 익히게 한다.

## 카드 생성/큐 정책

### 카드 생성

- 대상 항목(가시성 규칙, 2026-07-11 개정): **(a)** 공용 콘텐츠 출처가 있고 `approved` 인 항목, **또는 (b)** 내 개인 콘텐츠 출처가 있는 항목(`rejected` 제외 — 개인 등록분은 자동 편입).
- 오답 보기(distractor) 풀도 같은 가시성 규칙 적용 — 다른 사용자의 개인 항목이 보기에 노출되지 않는다.
- 사용자가 학습 시작 시점에 lazy 생성: 일일 신규 한도만큼 `review_cards(state=new)` 생성.
- 신규 도입 순서: 콘텐츠 최신순 + 레벨 낮은 타입 우선 (word → idiom → pattern → sentence). 사용자가 `levels_enabled`로 레벨을 끄면 해당 타입 제외.

### 일일 큐 구성 (GET /api/study/queue)

```
1. due 카드: due_at <= now, suspended=false — 최대 daily_review_limit
2. 신규 카드: 오늘 도입분이 daily_new_limit 미만이면 부족분 채움
3. 정렬: due 오래된 순 → 신규는 뒤에 배치, 같은 콘텐츠 연속 방지 셔플
4. 응답: 카드별 퀴즈 문항 (형식은 레벨별, 아래 참조) 20개 단위 페이지
```

세션 내 오답 카드는 큐 끝에 재삽입 — 그날 안에 다시 맞혀야 세션 완료로 집계.

## 레벨별 퀴즈 스펙

### 레벨 1 — 단어 맞추기 (word)

| 항목 | 내용 |
|------|------|
| 형식 | 4지선다, 2방향 랜덤 (`choice_en2ko`: 영단어 → 한글 뜻 / `choice_ko2en`: 한글 뜻 → 영단어) |
| 문맥 | 출처 문장(context_en)을 해당 단어 블랭크 처리해 하단에 표시 |
| 오답 보기 | 같은 word 풀에서 3개 샘플링 — 우선순위: 같은 품사 > 유사 난이도 > 랜덤. 정답과 뜻이 유사한 항목(동의어)은 제외 |
| 채점 | 선택 즉시. 정답이면 발음/뜻/예문 1.5초 노출 후 다음 |

### 레벨 2 — 숙어 맞추기 (idiom)

| 항목 | 내용 |
|------|------|
| 형식 | 문맥 빈칸(cloze) 4지선다 — 출처 문장에서 숙어 부분을 `___`로 비우고 보기 4개 |
| 오답 보기 | 같은 idiom 풀에서 3개, 문법적으로 빈칸에 들어갈 수 있는 형태 우선 |
| 보조 형식 | 문맥이 없는 항목은 레벨 1과 같은 뜻 매칭 선다로 폴백 |

### 레벨 3 — 패턴 맞추기 (pattern)

| 항목 | 내용 |
|------|------|
| 형식 | 패턴 완성 — 한글 문장 제시 + 영어 문장에서 패턴 코어 부분만 블랭크, 단어 칩(chip)을 순서대로 탭해 조립 |
| 예 | ko: "익숙해지는 데 시간이 걸려요" / en: `___ ___ ___ to get used to it` / 칩: [It] [takes] [time] [some] [makes] — 오답 칩 2개 섞음 |
| 채점 | 조립 결과 = pattern_template 적용 문장과 일치 여부 |
| 보조 형식 | 같은 패턴의 다른 출처 문장이 2개 이상이면 번갈아 출제 (패턴 일반화 학습) |

### 레벨 4 — 문장 통암기 (sentence)

| 항목 | 내용 |
|------|------|
| 문제 | 한글 번역(ko_text) 제시 + 괄호 안에 "영어식 사고" 힌트(hint_thinking) — 예: "저기에 나무가 한 그루 있어요 (있다, 나무 한 그루가, 저기에)" |
| 답안 | 영어 문장 전체 타이핑 |
| 1차 채점(코드) | 정규화(소문자, 문장부호/공백 정리, 축약형 통일: don't=do not) 후 비교. 관사/단복수 1글자 오차는 Levenshtein 거리 ≤ 2까지 "거의 정답" |
| 2차 채점(AI, 선택) | 정규화 불일치 && 글자수 70% 이상 일치 시 Claude Haiku로 의미 동등성 판정 (문법적으로 옳고 의미 동일 → 정답 처리 + 모범답안 병기). 호출 실패 시 1차 결과 사용 |
| 피드백 | 오답 시 diff 하이라이트 (빠진 단어/틀린 단어 색 표시) + 정답 문장 + 사고 힌트 재노출 |

## 학습 화면 흐름 (서비스 페이지)

```
홈(대시보드)
 ├─ 오늘의 학습: due N개 + 신규 M개 → [학습 시작] (/study/session 바로 진입)
 ├─ 레벨별 현황: 레벨 1-4 카드 수 / 마스터 수 (레고 브릭 쌓기 시각화)
 └─ 콘텐츠 라이브러리: 영상 재생 + 현재 문장 자막 + 구간 반복 듣기

학습 허브 (/study — 2026-07-14 IA 정리, 게임 허브와 동일 패턴)
 ├─ 오늘의 학습 CTA (due 수) → /study/session
 ├─ 어휘망 카드 → /study/network
 └─ 친구 카드 (받은 요청 배지·학습 중 수) → /friends (관전 뷰어: /study/watch)

학습 세션
 ├─ 진행바(브릭) + 문항 카드 (레벨별 형식)
 ├─ 정답: 브릭 스냅 효과 / 오답: 흔들림 + 정답 노출 → 큐 끝 재삽입
 └─ 세션 완료: 통계 (정답률, 소요시간, 내일 예정 수)
```

## 라이브러리 구간 반복 재생 (A-B 루프)

유튜브 콘텐츠의 스크립트를 문장 단위로 원어민 음성으로 들으며 공부한다 (2026-07-11 요구사항 추가).

| 기능 | 동작 |
|------|------|
| 플레이어 | YouTube IFrame Player API 임베드 (유튜브 약관상 임베드 재생만 허용) |
| 현재 문장 표시 | "마지막으로 시작한 세그먼트"의 en/ko 를 플레이어 아래 동기 표시 (범위 포함 매칭은 과거 병합 데이터의 부풀린 end 에서 3~4초 늦게 전환 — 2026-07-16 수정) |
| 자막 선행 표시 | 발화보다 미리 자막 전환 — 정시/0.5/1/1.5/2초 먼저, **기본 1초** (2026-07-16 요구). 기기별 localStorage 저장, 서버 설정 아님. 폴링 틱 보정 150ms 는 별도 |
| 이전/다음 문장 | 인접 세그먼트 `start_ms`로 시크 후 재생, `end_ms` 도달 시 정지 |
| 구간 반복 토글 | **체크 즉시** 화면의 현재 문장이 반복 구간으로 설정·재생 (2026-07-16 — 기존엔 이전/다음 버튼 뒤에만 동작). `end_ms` 도달 시 `start_ms`로 되감기, 해제 시 자연 재생. 루프 판정은 선행 없이 실시간 기준, 구간 길이 최소 1초 보장(퇴화 구간 보호) |
| 수기 콘텐츠 | 타임스탬프 없음(start_ms NULL) — 플레이어/반복 버튼 미노출 |

세그먼트 타임스탬프 품질(문자 비례 보간·클램프)은 [content-pipeline.md](content-pipeline.md) 문장 경계 시각 참조.

**전문(全文) 열람 제한 (2026-07-14 저작권 검토)**: 스크립트 전체 나열 UI 제거 —
전량 복제·전송이 공정이용 4요소 중 가장 불리한 지점이라 "재생 중 문장만 표시"로
전환. 권리자 삭제 요청 채널은 `/copyright` (privacy·라이브러리에서 링크).

- 구현: 클라이언트 폴링으로 `player.getCurrentTime()` 확인, end 초과 시 `seekTo(start)`. 자동 자막의 end_ms 가 문장을 넘길 수 있어 **재생 상한 8초**로 제한한다(2026-07-11 피드백).
- 데이터: `GET /api/contents/{id}` 가 세그먼트별 `start_ms`/`end_ms`와 `youtube_video_id`를 반환.

## API

| 메서드/경로 | 설명 |
|-------------|------|
| GET `/api/study/queue` | 오늘의 큐 + 문항 (20개 단위) |
| POST `/api/study/answer` | `{card_id, quiz_mode, answer, duration_ms}` → 채점 결과 + FSRS 갱신 + 다음 due |
| POST `/api/study/rate` | 레벨 4 자기평가 보정 `{card_id, rating}` |
| GET `/api/study/stats` | 대시보드: due/신규 수, 레벨별 현황, 일별 히트맵, 연속 학습일 |
| POST `/api/cards/{id}/suspend` | 카드 학습 제외/복귀 |
| GET/PATCH `/api/settings` | 일일 한도, 목표 기억률, 레벨 토글 |

## 엣지 케이스

| 케이스 | 처리 |
|--------|------|
| 오답 보기 풀 부족 (word 3개 미만) | 부족분은 사전 정의 더미 보기로 채움 (초기 데이터 적을 때) |
| 항목이 검수에서 rejected로 전환 | 기존 카드 suspended 처리 (이력 보존) |
| 밀린 복습 폭탄 (due 수백 개) | daily_review_limit로 상한, 오래된 순 우선 |
| 동일 항목 문맥 다수 | 출제 시 랜덤 문맥 선택 (과적합 방지) |
| 자정 경계 | "오늘" 판정은 사용자 타임존(기본 Asia/Seoul) 기준 |
