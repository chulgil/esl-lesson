# 스펙: 함께 목표 — 친구와 목표 세우고 서로 체크 (2026-08-12)

> 기획 의도: 친구끼리 목표를 세우고 달성을 서로 확인하면 동기부여가 된다
> (사용자 goal). 카톡 챗창 공지처럼 **대화방 상단에 고정된, 서로 편집하는
> 공유 영역** + 자동 집계 달성표.

## 벤치마크

| 서비스 | 차용한 것 |
|---|---|
| 카카오톡 공지 | 대화방 상단 고정·양쪽 모두 편집 — 위치와 편집 모델 |
| Duolingo Friend Quests | **친구와 공동 주간 목표를 앱이 자동 집계** (XP 합산 progress) — 수동 체크의 귀찮음 제거. 가장 유사한 선례 |
| Habitica 파티 퀘스트 | 내가 안 하면 파트너 진행이 깎이는 사회적 압박 — 합산 방식의 근거 |
| 스터디 그룹 앱 | 자유 체크리스트 — 측정 불가능한 약속("영어로만 대화하기")도 목표가 된다 |

설계 원칙: **자동(측정 가능) + 수동(약속) 이원화**. 자동만 있으면 유연성이
없고, 수동만 있으면 체크를 잊는다.

## 구성 (대화방 헤더 아래 접이식 "함께 목표" 보드)

1. **주간 달성표 (자동)** — 이번 주(KST 월요일 시작) 두 사람의 복습 수
   합산 vs 목표(기본 300, 탭해서 수정). 각자 기여가 나란히 보인다 —
   "내가 안 하면 우리 목표가 안 찬다". 달성 시 "달성!" 뱃지
2. **체크리스트 (수동)** — 자유 목표를 서로 추가·체크·삭제 (대화당 최대
   20개). 체크한 사람 표시 ("민지 달성"). 카톡 공지의 공동 편집 모델
3. **실시간 동기화** — 상대가 체크/추가하면 내 화면도 즉시 갱신
   (기존 채팅 WS 채널의 `goal.sync` 이벤트 → 재조회)

## 데이터 모델 (shared_goals)

| 필드 | 의미 |
|---|---|
| conversation_id | 대화방 스코프 (1:1 친구) |
| kind | "check"(수동) / "weekly_reviews"(주간 자동 — 대화당 1행, target 보관) |
| text | 체크 목표 문구 |
| target_value | 주간 목표치 (weekly 행만) |
| done / done_by | 체크 상태·체크한 사람 (check 행만) |
| created_by | 추가한 사람 |

## API (참가자만 — 403)

| 경로 | 역할 |
|---|---|
| GET /api/chat/with/{other_id}/goals | {items:[check...], weekly:{target, mine, theirs}} — weekly 진행은 ReviewLog 주간 집계 |
| POST /api/chat/with/{other_id}/goals | 체크 목표 추가 (max 20 — 422) |
| PATCH /api/chat/goals/{id} | text / done(done_by 기록) / target_value |
| DELETE /api/chat/goals/{id} | 삭제 |

모든 변경은 두 참가자에게 WS `{"t":"goal.sync","conversation_id"}` 푸시
(chat.deliver_ws 재사용) — 클라이언트는 재조회.

## UX·위장

- 3뷰 공통 `GoalBoard` — 대화방 헤더 아래 접이식 바 "함께 목표 n/m"
  (기본 접힘 — 채팅 시야 방해 금지). 펼치면 주간 달성표 + 체크리스트
- 오피스 위장(excel): "공동 시트" 풍 플레인 테이블 — 말풍선·캐릭터 금지
  계약 유지 (chat.md)
- 유니코드 이모지 금지 — 달성은 "달성!" 텍스트 뱃지

## 후속 (P2)

달성 시 XP 보너스(양쪽 지급), 주간 리셋 알림("이번 주 목표를 세워보세요"),
그룹(3인+) 확장.
