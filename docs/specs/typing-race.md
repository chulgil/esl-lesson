# 스펙: 영문 타자연습 — 문장 동기 레이스 (1~4인)

> 최종 검증: 2026-07-30 (코드 대조 완료) · P1 구현 완료

샘플 문장 하나를 모두가 동시에 타이핑 — **전원이 완성하면 다음 문장**.
문장은 내 학습 풀의 sentence 항목(가시성 규칙 준수)에서 나온다.

## 규칙

- 총 10문장, 문장당 제한 **최대 1분(60초)** (한 명이 멈춰도 진행 — 미완성은 정타 prefix 만 인정. 30→60초 2026-08-10, 느린 타이피스트가 문장 중간에 잘리는 문제)
- **공백 무시 정답 체크 (2026-08-10)**: 스페이스는 정답 판정에서 건너뛴다 — 입력·목표 둘 다 공백 제거 후 비교, 공백 입력은 오타로도 안 센다 (모바일 키보드 자동 공백 대응). 진행 줄/중계(chars)는 건너뛴 공백을 포함한 원문 인덱스 기준.
- 인원: 솔로(즉시 시작) / 방 코드 2~4인(방장이 시작)
- 화면: 샘플 문장 + **플레이어별 실시간 진행 줄**(정타 prefix 고스트) + 개별 WPM + **문장별 남은 시간**(10초 이하 빨간 강조 — 예고 없는 문장 전환 방지)
- 승부: 완성 문장 수 → 정타 수 → 누적 시간 순. 전 기준 동률 = 무승부
- WPM = (정타/5)/분, 정확도 = 정타/(정타+오타)
- 문장 풀 5개 미만이면 `sentences_insufficient` 안내
- **문장 길이 상한 80자** (120→80, 2026-08-10 사용자 — 긴 문장은 1분 제한에도 완주 불가라 출제 제외)
- **오답 회수 임계 (2026-08-11)**: 오타 수 >= max(2, 문장 길이의 5%) 또는 시간
  초과만 복습 문장으로 회수 — 철자 한둘 실수(수정 완성)가 "틀린 문장"으로 분류돼
  동기를 떨어뜨리던 문제. 결과 패널 머리말도 "복습하면 좋을 문장"
- **기록 히스토리 (2026-08-11)**: GET `/api/game/typing/history` — 최근 10판
  (날짜·평균/최고 타·정확도·승패). 로비 "내 기록" 리스트 — 지난번의 나를 이기는 동기
- 결과 stats 에 `cpm`/`peak_cpm` 저장 (TpResult 계약과 일치 — 히스토리 재료)
- 주간 명예의 전당(리더보드, `GET /api/game/leaderboards`)에 `peak_cpm` 기준으로
  편입 — 다른 4종 게임과 동일 집계 (구현 완료, 아래 P2 후보 목록에서 제외)
- **이탈 처리**: 대기실 이탈은 제거(호스트 이탈 시 방 해체). 진행 중 이탈은
  `done_current` 자동 통과로 레이스를 막지 않고, 참가자 전원이 이탈하면 진행
  태스크를 취소하고 세션을 즉시 정리한다(결과 미저장, `detach`/`_cleanup`,
  `services/game/typing_race.py`).

## 프로토콜 (WS /ws/game, `tp.*`)

| C→S | S→C |
|---|---|
| `tp.solo` / `tp.create` / `tp.join{code}` / `tp.begin`(방장) | `tp.room{code,host,players}` / `tp.start{sentences,total,sentence_seconds,countdown,players}` |
| `tp.typing{idx,chars}` (정타 prefix, 2자 단위 스로틀) | `tp.sentence{idx}` / `tp.typing{name,chars,wpm}` / `tp.done_mark{name,idx,wpm}` |
| `tp.done{idx,chars,errors}` / `tp.leave` | `tp.review{items[]}` (개인) / `tp.end{results,winner,aborted}` |

## 오답 → 원탭 학습 (2026-07-16, P2)

오타 완성(`errors>0`)·시간초과 문장을 기록해 정상 종료 시
`tp.review{items:[{item_id,en,ko}]}` 를 본인에게만 전송 (item_id 중복 제거 —
순환 풀 대응, aborted 미전송). 결과 화면 `ReviewPanel`(전 게임 공용 컴포넌트,
규칙은 quiz-royale.md "오답 → 원탭 학습" 과 동일). 문장 카드는 학습 레벨
'고급'에서 출제 — 패널 안내 문구로 고지.

## 재대결·출제 히스토리 (2026-08-20)

- **방 유지 재대결**: 방 게임(race) 정상 종료 시 방(세션·코드·플레이어)을 유지하고
  대기 상태로 복귀 — 방장 `tp.begin` 이 새 매치 행을 발급해 재입장 없이 다음 판.
  결과 화면에 "같은 방에서 다시하기"(방장)/대기 안내(게스트). 솔로·크래시 종료는 종전대로 정리
- **출제 히스토리**: 사용자별 최근 3판(30문장) 출제 문장을 제외하고 선정
  (`services/game/history.py ServedHistory` — 인메모리, 서버 재시작 시 초기화.
  남는 문장이 한 판 분량 미만이면 전체 풀 폴백). 규칙 원본: listening-bingo.md
