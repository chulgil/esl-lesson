# 어순 조립 레이스 (4번째 게임)

> 최종 검증: 2026-07-30 (코드 대조 완료)

> 섞인 단어 칩을 올바른 영어 어순으로 탭하는 동기 레이스, 1~4인.
> 한국어 화자의 최대 약점인 **어순**을 게임으로 훈련한다 — 기존 3종(어휘 반사·뜻 매칭·타이핑)이 못 다루던 근육.

## 게임 규칙

| 항목 | 값 |
|---|---|
| 문장 수 | 8문장 (전원 동일, 시드 셔플) |
| 문장당 제한 | 60초 — 전원 완성 또는 시간 초과 시 다음 문장 (40→60초 2026-08-10, 문장형 게임 공통 최대 1분) |
| 칩 범위 | 단어 4~12개 문장만 출제 (짧으면 퍼즐이 안 되고 길면 화면 넘침) |
| 점수 | 완성 = 기본 100 + 시간 보너스(최대 100) − 실수당 10, **최소 30 보장**(포기 방지) |
| 판정 | 클라이언트 즉시 판정(칩 탭마다) — 오답 칩은 흔들리고 제자리, 정답 칩만 조립 영역으로 |
| 승자 | 점수 多 → 실수 少 → 누적 시간 少 (전 동률 무승부) |
| 문장 풀 | 타자연습과 동일 — sentence 항목, 가시성 규칙(공용 승인 ∪ 내 개인) |

## 구성

- **서버**: `services/game/scramble.py` — 타자 레이스와 동일 진행 모델 (칩 셔플은 정답 어순 회피 재시도)
- **저장**: `scramble_races` (d6e7f8a9b0c1) — p1/p2_score, stats JSONB, 조회 인덱스 3종 선제 생성
- **WS**: `sc.solo/create/join/begin/progress/done/leave` → `sc.room/start/sentence/progress/done_mark/review/end`
  - 점수는 **서버 시계**로 계산 (클라이언트는 mistakes 만 보고)
  - `sc.review{items[]}` (개인, 2026-07-16): 실수(`mistakes>0`)·시간초과 문장의
    학습 항목 — 결과 화면 `ReviewPanel` 원탭 학습 추가 (규칙: quiz-royale.md)
- **연동**: 게임 허브 카드, 내 최고 기록(`scramble_best_score`), 주간 명예의 전당, XP(참여 20),
  업적(첫 승리·게임 단골 포함), 친구 초대(`iv.invite game=scramble` → `/game/scramble?join=`)

## 치팅 노트

정답 어순이 클라이언트에 내려간다 (즉시 판정·오프라인 유예를 위해) — 타자연습과 동일한
신뢰 모델(친구 간 캐주얼 대전). 랭킹 보상이 커지면 서버 판정으로 전환 검토.
