# 데일리 단어 퍼즐

> 하루 한 단어(전원 동일) 워들 — "몇 번 만에 맞혔나" 공유가 리텐션 훅. 게임 허브 진입.

| 항목 | 값 |
|---|---|
| 단어 선택 | 승인 단어(4~8자 순수 알파벳) 중 **랑데부 해싱**(날짜+단어) — 풀 증가에도 답 안정 |
| 진행 저장 | daily_puzzle_plays (user_id, day UNIQUE) — 첫 추측 시 정답을 행에 고정 |
| 채점 | 서버 — 표준 워들 규칙(중복 글자는 남은 개수만 노랑). 정답은 종료 시에만 공개 + 뜻 표시(학습 모먼트) |
| API | GET /api/game/puzzle, POST /api/game/puzzle/guess (6회 제한, 422/409 가드) |

XP·리더보드 미연동 (의도) — 판이 아니라 데일리 습관 장치.
