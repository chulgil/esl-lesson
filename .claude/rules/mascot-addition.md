# Mascot Addition — 신규 마스코트/악세사리 추가 체크리스트

> 트리거: "새 캐릭터/마스코트/악세사리 추가" 요청 시 이 체크리스트 전체를 순서대로.
> 배경: 2026-08-11 사용자 지시 — "테마나 캐릭터가 추가될 때 모든 곳에 반영될 수
> 있도록 강력하게, 누락 없이". 마스코트는 좌하단 상시 노출 + 프로필 아바타 +
> 공유 카드 + 상점 미리보기 4곳에 동시에 나타난다 — 한 곳이라도 빠지면
> "반쪽 캐릭터"가 된다.

## 원칙

- **카탈로그 단일 근거**: `backend/app/services/mascots.py` (키·라벨·가격).
  프론트 라벨은 `mascots.tsx` MASCOT_LABELS/OUTFIT_LABELS — 두 곳이 전부다.
- 보유 = `item_grants` 행, 소비 = `xp_spends`(reason="mascot:키"/"outfit:키").
- 체크리스트 **전부 완료 + 시각 검증 통과** 전에는 완료 선언 금지
  (verification.md Iron Law).

## 체크리스트

### 1. 백엔드

- [ ] `services/mascots.py` MASCOTS/OUTFITS 에 키·라벨·가격 추가 — 가격은 일일
  획득량(~500XP) 기준 층위 (악세 300~1000 / 마스코트 1500~2500, 벤치마크
  proposal/xp-shop-mascot-2026-08.md)

### 2. 프론트 렌더 (`frontend/src/components/theme/mascots.tsx`)

- [ ] 캐릭터 SVG — 공통 캔버스 104x88, 좌하단 빼꼼 구도, `flip`(말풍선 역반전)·
  `avatar`(말풍선 없음·"6 12 88 76" 크롭·정지) 두 모드 모두 구현
- [ ] **악세 4종 앵커를 캐릭터별로 명시 배치** — 공용 좌표를 쓰지 말 것.
  안경=눈 위, 목도리=입 아래(입을 가리면 안 됨 — 2026-08-11 브리키/몽이 사고),
  리본=머리 측면(부유 금지), 왕관=정수리
- [ ] idle 애니메이션 — globals.css `mascot-anim-*` 키프레임 추가 (성격에 맞는
  미세 움직임, 2.5~4s 주기), MASCOT_LABELS 등록

### 3. 시각 검증 (필수 — 여러 번, 2026-08-11 사용자 지시)

`/design/mascots` QA 픽스처에서 **원본/반전/아바타 3변형 x 악세 조합** 확인:

- [ ] 말풍선 글자 정방향 (반전 변형에서)
- [ ] 악세가 입·눈을 가리지 않음 (확대 스크린샷으로 — 축소본은 뭉개져 놓친다)
- [ ] idle 애니메이션 작동 — 시간차 좌표 측정 (샘플 6개 전원 상이)
- [ ] 아바타 크롭이 캐릭터를 자르지 않음

### 4. 노출 표면 (자동 확인 — 누락 시 여기서 잡는다)
